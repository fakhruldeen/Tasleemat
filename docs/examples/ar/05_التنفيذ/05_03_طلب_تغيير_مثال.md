## 1. معلومات مقدم الطلب

**اسم مقدم الطلب ومنصبه:**
تم توثيق هذا القسم واعتماده بالتفصيل وفق خطة المشروع التشغيلية لشركة القمة للحلول المؤسسية المتقدمة، بما يضمن التوافق الكامل مع أفضل ممارسات الحوكمة الصادرة عن مكتب إدارة المشاريع (PMO).

---

## 2. تصنيف التغيير

**فئة التغيير:**
- [ ] النطاق
- [ ] الجدول الزمني
- [ ] التكلفة
- [ ] الجودة
- [ ] الموارد
- [ ] أخرى: تم تحديده وتوثيقه بالتفصيل ليتوافق مع الخطة التشغيلية لشركة القمة.

**نوع التغيير:**
- [ ] إلزامي (مثل: قانوني أو تنظيمي)
- [ ] اختياري
