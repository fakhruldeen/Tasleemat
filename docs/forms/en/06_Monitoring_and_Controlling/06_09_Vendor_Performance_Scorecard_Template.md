<!-- LLM INSTRUCTIONS: Fill in the [ Add details... ] placeholders

Context and Definition:
A vendor performance scorecard records how an external supplier performed
against measures the project agreed in advance. The order of the columns is
the order the decisions happen in: the metric, the target that was agreed
for it, what was actually measured, the gap between them, and what is
being done about the gap.

The target is what makes the form worth completing. A score with no target
behind it cannot be argued with in either direction - the supplier regards
it as good, the project regards it as adequate, and nothing in the
document settles the disagreement. Agreeing the target first is the entire
discipline, and a target written after the result is known is not a target.

A scorecard is a period record rather than a running judgement. It is kept
per supplier per period, compared against the previous period, and read by
whoever owns the contract. A supplier that is performing well is left
alone, and a supplier that is not gets a corrective action with a name on
it and a date attached.

It can receive information from:
*   The contract or statement of work
*   Acceptance records, which are the raw material for quality measures
*   Issue and change logs raised against the supplier

It provides information to:
*   Contract closeout report, which reads the record across all periods
*   Procurement audit
*   Project status report, where a supplier shortfall is a schedule risk

Tailoring Tips:
*   Agree the target before the period starts. Every target written
    afterwards is a description of what happened, and the variance column
    then computes a gap between the outcome and itself.
*   State the measure with the score. A number whose measurement method
    changed between periods cannot be compared to one that did not, and
    the comparison is the only reason the number exists.
*   Write a corrective action only where there is a shortfall, and name
    who owns it. A variance with no response is recorded again next period,
    because the only thing that changed in between was the number.

Alignment:
The vendor performance scorecard should be aligned and consistent with:
*   The contract or statement of work, because the measures are contract
    measures and not the project's preferences
*   Procurement audit, which reads the period records as its evidence
*   Contract closeout report, which needs the trend rather than one period

Section Instructions:
*   Vendor Performance Scorecard Entries: for each measure the project
    tracks for this supplier, give the metric named so both sides would
    recognise it, the target agreed for the period, the score actually
    measured and how, the variance with its direction, and the corrective
    action with an owner and a date where the variance is a shortfall.
-->
