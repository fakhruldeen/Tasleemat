## 🎯 مرحباً بك في «تسليمات»

**تسليمات (Tasleemat)** هو نظام تشغيل مؤسسي متكامل وشامل لمكاتب إدارة المشاريع (PMO)، مبني وفق أعلى المعايير العالمية لمعهد إدارة المشاريع (PMI PMBOK® الإصدارات 6 و 7 و 8). يوفر النظام **102 نموذج تسليم ثنائي اللغة (عربي وإنجليزي)** بصيغة Markdown فائقة الجودة، مع هياكل برمجية رقمية (`*.json`, `*.csv`) وأمثلة تطبيقية واقعية 100%.

سواء كنت تدير برنامج تحول رقمي استراتيجي بملايين الريالات، أو مشروعاً سريعاً يتبع أجايل (Agile)، أو نموذج ذكاء اصطناعي توليدي مبتكر؛ تمنحك تسليمات خط الأساس الحوكمي الدقيق دون أي هدر إجرائي أو بيروقراطية معطلة.

```mermaid
flowchart LR
    A["1. تحديد مستوى المشروع"] --> B["2. تخصيص النماذج"]
    B --> C["3. اعتماد خط الأساس"]
    C --> D["4. التنفيذ والمراقبة"]
    D --> E["5. عبور البوابات"]
    E --> F["6. الإغلاق وحصاد القيمة"]
```

## 🧭 خطوات البدء التشغيلي خطوة بخطوة

### المرحلة 1: الأيام 1 إلى 7 — الاستكشاف والتصنيف المبدئي
1. **تحديد مستوى المشروع وتصنيفه:**
   - راجع وثيقة [`05_tailoring_profiles.md`](05_tailoring_profiles.md).
   - صنّف مبادرتك ضمن: **المستوى 1 (المشاريع الكبرى / الاستراتيجية)**، أو **المستوى 2 (المشاريع المتوسطة)**، أو **المستوى 3 (المشاريع الصغيرة / الرشيقة)**، أو **المستوى 4 (مشاريع الذكاء الاصطناعي والتقنيات الناشئة)**.
2. **فهم متطلبات بوابات العبور (Stage-Gates):**
   - راجع دليل [`04_stage_gates_and_governance.md`](04_stage_gates_and_governance.md) للتعرف على بوابات المراجعة الست (بوابة 0 إلى بوابة 5).
3. **صياغة وثائق التأسيس الاستراتيجي:**
   - على مستوى المحفظة/البرنامج: إعداد [`00_01 خارطة طريق المحفظة`](../../forms/ar/00_إدارة_البرامج_والمحافظ/01_خارطة_طريق_المحفظة/) و[`00_06 مصفوفة مواءمة الأهداف والنتائج الرئيسية`](../../forms/ar/00_إدارة_البرامج_والمحافظ/06_مصفوفة_مواءمة_الأهداف_والنتائج_الرئيسية/).
   - على مستوى المشروع: إعداد [`01_01 دراسة الجدوى`](../../forms/ar/01_الأعمال_وتسليم_القيمة/01_دراسة_الجدوى_(Business_Case)/) و[`03_01 ميثاق المشروع`](../../forms/ar/03_البدء/01_ميثاق_المشروع/).

## 🗂️ هيكلية النماذج والأدلة والأمثلة التطبيقية

تتكون كل حزمة نموذج في «تسليمات» من منظومة رباعية مترابطة:

```
forms/ar/03_البدء/01_ميثاق_المشروع/
├── 03_01_ميثاق_المشروع_قالب.md       # القالب الخام الجاهز للتعبئة
├── 03_01_ميثاق_المشروع_دليل.md      # دليل الإرشادات والاعتماديات ومصفوفة RACI
├── 03_01_ميثاق_المشروع.json          # البنية الرقمية ومخطط البيانات
└── 03_01_ميثاق_المشروع.csv           # أسماء أعمدة الجداول والبيانات المنظمة

examples/ar/03_البدء/01_ميثاق_المشروع/
└── 03_01_ميثاق_المشروع_مثال.md      # مثال مؤسسي تطبيقي مكتمل 100%
```

1. **لمعد الوثيقة (مدير المشروع / قائد الفريق):**
   - افتح ملف `*_دليل.md` أولاً لفهم المدخلات الإلزامية والاعتماديات السابقة.
   - انسخ ملف `*_قالب.md` إلى مجلد مشروعك.
   - املأ الحقول بين الأقواس المعقوفة `[ حدد ... ]`.
   - استعن بملف `*_مثال.md` في مجلد `examples/` للاسترشاد بنموذج مكتمل واقعي.
2. **للمعتمد والموقع (راعي المشروع / مدير PMO):**
   - تحقق من **جدول المراجعة والاعتماد المؤسسي** أسفل الوثيقة.
   - تأكد من استيفاء الاعتماديات السابقة وفق [`07_document_dependencies.md`](07_document_dependencies.md).
