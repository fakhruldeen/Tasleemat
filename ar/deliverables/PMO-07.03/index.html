1. مفهوم الوثيقة وطبيعتها

وثيقة مشروع رسمية متوافقة مع تسليمات تُعرف بـ إغلاق المشروع أو المرحلة، وتُستخدم لتوثيق أداء المشروع النهائي مقارنةً بأهداف المشروع. تُراجع الأهداف الواردة في ميثاق المشروع ويُوثَّق دليل على تحقيقها. وإذا لم يتحقق هدف، أو كان هناك انحراف، فيُوثَّق ذلك أيضًا، إلى جانب معلومات إغلاق المشتريات.

ملخص الأداء مصفوفة: النطاق والجودة صفوفًا، مقابل الأهداف ومعايير الإنجاز وكيف تحققت أعمدة. وقسم الانحرافات مصفوفة ثانية: الوقت والتكلفة صفوفًا، مقابل الأهداف والنتيجة النهائية والانحراف والتعليقات أعمدة.

2. القيمة والأهمية الاستراتيجية

لتقديم المؤسسة سجلًا دائمًا لما قدّمه المشروع وكم كلّفه، حتى تستند القرارات لأعمال المستقبل إلى الأدلة لا إلى الذاكرة، وحتى لا يضيع بصمت أي بند بقي مفتوحًا عند الإغلاق.

3. التوقيت ودواعي الإعداد والتحديث

يُعد هذا المخرج ضمن مجموعة الإغلاق في دورة حياة المشروع. وهو يدعم العملية 4.7 إغلاق المشروع أو المرحلة، ويُعد عند إغلاق المرحلة في المشاريع الطويلة، وعند إغلاق المشروع في المشاريع الأقصر.

4. الأدوار والمسؤوليات (RACI)

المسؤوليات: يُعده مدير المشروع، ويُعتمد من راعي المشروع أو العميل ومن مسؤول العمليات أو الخدمة الذي يستلم المنتج، ويُؤرشف ضمن سجلات المشروع.

إرشادات التخصيص والمواءمة

  • عند العمل بدورة حياة تزايدي أو منهجية تطوير رشيقة، قد يفيد تسليم عنصر أو خدمة أو قدرة رئيسية بتقرير إغلاق رسمي للمرحلة.
  • للمشاريع التي تنتمي إلى برنامج، خصص المحتوى لتلبية احتياجات البرنامج.
  • أضف صفًا إلى مصفوفة ملخص الأداء أو الانحرافات لكل مجال أو مقياس إضافي يتابعه المشروع.
  • استخدم معلومات مشروعك لتحديد أفضل نهج.

المحاذاة والترابط المؤسسي

ينبغي أن يتسق هذا الإغلاق مع الوثائق التالية: * خطة إدارة المشروع (جميع المكونات) * قبول المنتج * ملخص الدروس المستفادة

5. إرشادات تعبئة الحقول والبيانات

لإكمال تقرير إغلاق المشروع أو المرحلة بشكل دقيق واحترافي، يجب على المسؤول المكلف تعبئة الأقسام التالية بناءً على سياق المشروع (مع التأكد من مراجعة parameters.md للتحقق من المتغيرات العامة للمشروع):

  • وصف المشروع / الوصف: قدّم وصفًا على مستوى ملخص للمشروع أو المرحلة: ما هو، وهدفه، وحدوده. اجعل ذلك على مستوى الملخص، وأشر إلى ميثاق المشروع للتفاصيل.
  • إدارة الفوائد / كيف تحققت الفوائد: صف كيف حقق المنتج أو الخدمة أو النتيجة النهائية الفوائد التي أُنشئ المشروع لتحقيقها. حدد الفائد والدليل على تحققها، مع التمييز بين فائدة تحقق فعلًا وأخرى لم تتحقق بعد.
  • إدارة الفوائد / حالة تحقق الفوائد: حالة تحقق كل فائدة حاليًا، ومن المسؤول عن متابعتها بعد انفصال فريق المشروع. الفائدة التي لا يوجد لها مالك عند الإغلاق هي فائدة لن يتم قياسها.
  • الاحتياجات التجارية / كيف تحققت الاحتياجات التجارية: صف كيف حقق المنتج أو الخدمة أو النتيجة النهائية الاحتياجات التجارية المحددة في خطة الأعمال.
  • الاحتياجات التجارية / الاحتياجات غير المحققة: أي حاجة تجارية لم تتحقق، وما الخطوة التالية بعد إغلاق المشروع. الحاجة التي لا تُذكر هنا سيفترضها من يرث المنتج أنها تحققت.
  • ملخص الأداء / النطاق / الأهداف: صف أهداف النطاق اللازمة لتحقيق الفوائد المخطط لها للمشروع.
  • ملخص الأداء / النطاق / معايير الإنجاز: وثّق معايير محددة وقابلة للقياس اللازمة لإكمال أهداف النطاق. اذكر كل معيار بحيث يمكن الإجابة عنه بتحقق أو عدم تحقق، وأشر إلى خط أساس النطاق.
  • ملخص الأداء / النطاق / كيف تحققت: اذكر الدليل على تحقّق معايير الإنجاز. وقدّم مصدر الدليل، مثل الوثيقة أو نتيجة الاختبار أو سجل القبول، وليس الاستنتاج المستخلص منه فقط.
  • ملخص الأداء / الجودة / الأهداف: صف أهداف الجودة والمعايير اللازمة لتحقيق الفوائد المخطط لها للمشروع.
  • ملخص الأداء / الجودة / معايير الإنجاز: وثّق المعايير المحددة والقابلة للقياس اللازمة لتحقيق أهداف جودة المنتج والمشروع.
  • ملخص الأداء / الجودة / كيف تحققت: أدخل معلومات التحقق والإثبات من نموذج قبول المنتج. وأشر إلى ذلك النموذج بدلًا من إعادة كتابته، حتى لا تتباعد السجلات.
  • الانحرافات / الوقت / الأهداف: أهداف الوقت المخطط لها: المدة المعتمدة في خط أساس الجدول الزمني وتاريخ الإنجاز المخطط.
  • الانحرافات / الوقت / النتيجة النهائية: تاريخ الإنجاز الفعلي والمدة الفعلية.
  • الانحرافات / الوقت / الانحراف: الفرق بين المخطط والفعلي بالأيام أو الأسابيع، مع السبب. وإذا أُنجز المشروع مبكرًا، فاذكر ذلك واشرح السبب، فالانحراف الإيجابي غير المفسّر يخفي خطأ في التخطيط تمامًا كما يخفيه التأخير.
  • الانحرافات / الوقت / التعليقات: أي ترتب على انحراف الوقت للمؤسسة، مثل تفويت نافذة سوقية، وأي بند ما زال مفتوحًا عند الإغلاق.
  • الانحرافات / التكلفة / الأهداف: خط أساس التكلفة المعتمد، أو إجمالي الميزانية عند الإنجاز إذا لم ينطبق خط أساس.
  • الانحرافات / التكلفة / النتيجة النهائية: إجمالي ما أنفق فعليًا عند الإنجاز، مع بيان ما إذا كان يشمل مبلغ الاحتياطي المستهلك أو الاحتياطي المُحرَّر.
  • الانحرافات / التكلفة / الانحراف: الفرق بين المخطط والفعلي بالعملة ونسبة مئوية، مع السبب.
  • الانحرافات / التكلفة / التعليقات: أي ترتب على انحراف التكلفة للمؤسسة، مثل مطالبة أو تحويل ميزانية لا يزال مطلوبًا، وأي بند ما زال مفتوحًا.
  • المخاطر والمشكلات / المخاطرة أو المشكلة: المخاطرة أو المشكلة، ومصدرها. اذكر المرجع من سجل المخاطر أو المشكلات بدلًا من إعادة كتابته.
  • المخاطر والمشكلات / الاستجابة والحل: ما تم بشأنه وفعاليته. واذكر بوضوح ما إذا كان ناجحًا.
  • المخاطر والمشكلات / التعليقات: ما بقي مفتوحًا، ومن يملكه بعد الإغلاق. والبند غير المحلول المتنقل دون مستلم محدد لم ينتقل فعليًا.
  • إغلاق المشتريات / العقود المغلقة: العقود التي تم إغلاقها، مع القيمة النهائية وتاريخ إغلاق كل منها. وإذا لم تُستخدم المشتريات، فاذكر ذلك بوضوح بدلًا من ترك القسم فارغًا.
  • إغلاق المشتريات / الالتزامات المُباة: الالتزامات والضمانات ومستويات الخدمة التي تم الوفاء بها أو نقلها أو ما زالت قائمة، مع ذكر المالك لكل منها.
  • إغلاق المشتريات / المطالبات والمنازعات المسوّاة: أي مطالبة أو منازعة سُوّت قبل الإغلاق، وأي لم تُسوَّ. فالمطالبة غير المسوّاة التزام يسلّمه المشروع.
