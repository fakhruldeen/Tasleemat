⌨️ أداة سطر الأوامر (CLI)

دليل أداة الطرفية وسطر الأوامر والأتمتة

المرجع الشامل لأداة التشغيل عبر سطر الأوامر (tasleemat) لأتمتة بيئات العمل، تهيئة مجلدات المشاريع، البحث في الفهرس المعياري، التوليد الآلي عبر الذكاء الاصطناعي، والتشغيل في البيئات المعزولة.

الأقسام الفنية: 📖 بوابة المطورين⌨️ أداة الطرفية والأتمتة🐍 مكتبة بايثون (SDK)🔌 خادم بروتوكول MCP📐 المخططات والتحقق🤖 أسراب الوكلاء و CI/CD

1. معمارية الأداة ومتغيرات البيئة البرمجية

تم بناء أداة tasleemat كأداة طرفية بلغة بايثون الخالصة بدون أي مكتبات خارجية ثقيلة، وهي تعمل مباشرة على أنظمة Linux و macOS و Windows. توفر الأداة نمطين للتشغيل: نمط المعالج التفاعلي الموجه لمديري المشاريع والممارسين، و نمط المعاملات المؤتمتة (Flags Mode) الموجه لسكربتات Bash وأنظمة CI/CD.

متغيرات البيئة العامة (Environment Variables)

المتغير القيمة الافتراضية الوصف والوظيفة
TASLEEMAT_HOME ~/.tasleemat المجلد الرئيسي للبيانات المحلية المؤقتة وسجلات المشاريع.
TASLEEMAT_CONFIG_FILE ~/.tasleemat/config.json ملف حفظ مفاتيح واجهات الذكاء الاصطناعي المشفر بصلاحيات أمان 0600.
TASLEEMAT_DEFAULT_LANG ar اللغة الافتراضية للتوليد في حال عدم تمرير خيار --lang.
TASLEEMAT_NO_COLOR 0 تعيينه إلى 1 لتعطيل ألوان ANSI في سجلات التشغيل النصية.

مصفوفة رموز الخروج القياسية (Exit Codes)

تلتزم الأداة بمعايير POSIX لرموز الخروج لتمكين خطوط الأتمتة من اتخاذ القرارات بدقة:

  • 0: نجاح كامل (SUCCESS) - تم تنفيذ الأمر بنجاح وحفظ كافة المخرجات.
  • 1: خطأ تشغيلي أو فشل تحقق (ERROR) - عدم تطابق البيانات مع مخطط JSON أو تعذر الاتصال بالنموذج.
  • 2: معاملات غير صالحة (INVALID ARGS) - خيار غير معروف أو مستوى حوكمة غير مسجل.
  • 127: تسليمة غير موجودة (NOT FOUND) - رمز التسليمة المحدد غير موجود في الفهرس المعياري.

2. المرجع الشامل لكافة الأوامر والمعاملات

أ. tasleemat init (تهيئة وتجهيز بيئات عمل المشاريع)

يقوم أمر init ببناء بيئة عمل متكاملة للمشروع مخصصة وفق مستوى الحوكمة (المستوى 1 أو 2 أو 3) وحزمة المنهجية المتبعة. ينشئ الأمر لكل تسليمة حزمة متكاملة من 5 ملفات: القالب الأساسي (Markdown)، دليل الممارس (Markdown)، مثال واقعي مكتمل (Markdown)، مخطط التحقق الآلي (JSON Draft 2020-12)، و قاموس الحقول والبيانات (CSV). 

# نمط المعالج التفاعلي (يسألك خطوة بخطوة عن بيانات المشروع)
tasleemat init

# نمط الأتمتة الكامل عبر المعاملات (مشروع رشيق من المستوى 2 باللغة العربية)
tasleemat init \
  --tier 2 \
  --pack agile \
  --lang ar \
  --code "PRJ-2026-CLOUD" \
  --name "منصة التحول الرقمي السحابي" \
  --pm "سارة الأحمد" \
  --sponsor "د. خالد المنصور" \
  --out ./projects/PRJ-2026-CLOUD \
  --force

# مشروع استراتيجي كبير (المستوى 1) بكامل الوثائق ثنائية اللغة (عربي وإنجليزي)
tasleemat init \
  --tier 1 \
  --pack hybrid \
  --lang both \
  --code "PRJ-CORE-MIGRATE" \
  --name "برنامج استبدال الأنظمة المصرفية الأساسية" \
  --pm "فهد الحربي" \
  --sponsor "الرئيس التنفيذي للعمليات" \
  --out ./enterprise_workspace
المعاملات والخيارات المدعومة:
  • --tier <1|2|3>: مستوى حجم وحوكمة المشروع (1 = مشاريع كبرى/استراتيجية، 2 = مشاريع قياسية، 3 = مشاريع رشيقة سريعة). القيمة الافتراضية: 2.
  • --pack <general|agile|ai|predictive|hybrid>: حزمة منهجية التسليم. القيمة الافتراضية: general.
  • --lang <en|ar|both>: لغة توليد الملفات (عربي، إنجليزي، أو كلتا اللغتين). القيمة الافتراضية: ar.
  • --code <string>: الرمز التعريفي للمشروع (مثل: PRJ-2026-001).
  • --name <string>: الاسم الرسمي المعتمد للمشروع.
  • --pm <string>: اسم مدير المشروع المسؤول.
  • --sponsor <string>: اسم الراعي التنفيذي للمشروع.
  • --out <path>: مسار مجلد الإخراج في نظام الملفات.
  • --force: استبدال المجلد الحالي في حال وجوده دون توقف.

ب. tasleemat list و search (استعراض الفهرس والبحث)

استعراض الـ 114 تسليمة معيارية مباشرة من الطرفية مع إمكانية التصفية بحسب مراحل المشروع، مستويات الحوكمة، واستخراج المخرجات بصيغة JSON. 

# استعراض كافة التسليمات باللغة العربية أو الإنجليزية
tasleemat list --lang ar
tasleemat list --lang en

# تصفية التسليمات بحسب مرحلة دورة حياة المشروع (المراحل من 00 إلى 07)
tasleemat list --phase 04 --lang ar

# تصفية التسليمات بحسب المستوى والمنهجية
tasleemat list --tier 3 --pack agile

# تصدير التسليمات بصيغة JSON المعيارية للمعالجة البرمجية
tasleemat list --json | jq '.[0]'

# البحث الذكي الشامل بالعناوين والكلمات المفتاحية والرموز
tasleemat search "ميثاق" --lang ar
tasleemat search "Charter" --lang en
tasleemat search "PMO-04.08.02"

ج. tasleemat config (إدارة مفاتيح وبيئات الذكاء الاصطناعي)

إدارة مفاتيح الربط مع نماذج الذكاء الاصطناعي والنماذج المحلية بشكل آمن في الملف المحلي ~/.tasleemat/config.json بصلاحيات مقيدة. 

# إعداد وتفعيل Google Gemini
tasleemat config set --provider gemini --model gemini-2.5-flash --key "AIzaSy..."

# إعداد وتفعيل OpenAI GPT-4o
tasleemat config set --provider openai --model gpt-4o --key "sk-proj-..."

# إعداد وتفعيل Anthropic Claude
tasleemat config set --provider anthropic --model claude-3-5-sonnet-20241022 --key "sk-ant-..."

# إعداد خادم محلي Ollama (للبيئات المعزولة وعالية الأمان بدون إنترنت)
tasleemat config set --provider ollama --model llama3.2 --endpoint "http://localhost:11434"

# عرض الإعدادات الحالية (يتم حجب المفاتيح السرية تلقائياً بنجوم)
tasleemat config show

# إعادة تعيين مفاتيح مزود معين
tasleemat config reset --provider openai

د. tasleemat generate (التوليد الذكي للوثائق)

توليد مسودات الوثائق بصيغة Markdown من مذكرات الاجتماعات الخام باستخدام النماذج اللغوية، مع خيار المحاكاة بدون إنترنت (--mock). 

# توليد ميثاق المشروع (PMO-03.01) من ملف مذكرات الاجتماع
tasleemat generate \
  --form PMO-03.01 \
  --notes ./kickoff_notes.txt \
  --lang ar \
  --out ./Project_Charter.md

# التمرير المباشر للنصوص عبر مجرى الإدخال القياسي (stdin piping)
cat << 'EOF' | tasleemat generate --form PMO-04.08.02 --lang ar --out ./Risk_Register.md -
المشروع يواجه احتمالية تأخر وصول الخوادم بنسبة 40%، مما قد يعطل الإطلاق أسبوعين.
المسؤول عن المتابعة هو مهندس البنية التحتية.
EOF

# نمط المحاكاة بدون استهلاك أي رموز (mock mode) لاختبارات خطوط CI/CD
tasleemat generate \
  --form PMO-03.01 \
  --notes "بيانات وهمية للاختبار" \
  --mock \
  --out ./mock_charter.md

هـ. tasleemat test و tasleemat mcp

تشغيل حزم الاختبارات الداخلية والتحقق من صحة البيئة، أو إطلاق خادم بروتوكول سياق النموذج (MCP): 

# تشغيل كامل حزمة الاختبارات الآلية (أكثر من 140 اختباراً)
tasleemat test -v

# تشغيل الاختبارات مع التوقف عند أول خطأ
tasleemat test -v --failfast

# تشغيل خادم بروتوكول MCP عبر بروتوكول stdio للتكامل مع Cursor و Claude
tasleemat mcp

و. tasleemat tui (محطة العمل التفاعلية ثنائية اللغة في الطرفية)

تشغيل واجهة المستخدم الطرفية الغنية (TUI) والمبنية بمكتبة Textual لدعم التفاعل بالفأرة ولوحة المفاتيح. تتميز بدعم كامل ودقيق للغة العربية تشكيلاً واتجاهاً (BiDi & Reshaping)، ومعاينة حية لوثائق Markdown ومخططات JSON Schema، ومعالج تهيئة تفاعلي، ومصفوفة بوابات المرحلة، واستوديو التوليد بالذكاء الاصطناعي، وتكامل فوري بنقرة واحدة مع 8 بيئات وكلاء ذكاء اصطناعي. 

# تثبيت الحزمة مع إضافات واجهة الطرفية TUI
pip install "tasleemat[tui]"

# تشغيل محطة العمل الطرفية التفاعلية
tasleemat tui

# التشغيل المباشر باللغة العربية
tasleemat tui --lang ar

# الاسم البديل المختصر للأمر
tasleemat ui
8 مساحات عمل ومزايا متقدمة في الواجهة:
  • 1. معالج تهيئة المشاريع (Wizard): معالج مرشد في 5 خطوات لاختيار مستوى الحوكمة والمنهجية وتوليد بيئة العمل مع حقن إعدادات وكلاء الذكاء الاصطناعي تلقائياً.
  • 2. مستكشف التسليمات (Explorer): استعراض فوري لـ 114 وثيقة بتصميم مقسوم، مع فلاتر المراحل والمستويات، ومعاينة حية لنصوص Markdown وبنية JSON Schema المرافقة.
  • 3. متصفح بوابات المرحلة (Gates): تصفح بوابات الحوكمة الخمس (Gate 0 إلى Gate 5) واستعراض معايير الدخول وقوائم التحقق التفاعلية للاعتماد.
  • 4. المعجم الموحد (Lexicon): بحث لحظي ضبابي في 114 مصطلحاً حوكمياً باللغتين العربية والإنجليزية مع إمكانية الانتقال الفوري لوثيقة المصطلح.
  • 5. استوديو الذكاء الاصطناعي (AI Studio): مساحة تفاعلية لصياغة وتوليد الوثائق من مذكراتك وملاحظاتك مع بث حي ومباشر للنصوص داخل الطرفية.
  • 6. إدارة نماذج الذكاء الاصطناعي (LLM Config): حرية كاملة في تحديد أي نموذج دون قيود، مع دعم كامل لـ OpenAI و Anthropic و Gemini و Groq و OpenRouter والنماذج المحلية المتوافقة مع معيار OpenAI (مثل vLLM و Ollama و Together).
  • 7. مركز ربط الوكلاء (Agent Hub): توليد فوري لإعدادات وقواعد وقوالب الوثائق وخادم MCP بنقرة واحدة لـ 8 بيئات عمل ذكاء اصطناعي: Cursor و Antigravity و Claude Desktop و VS Code و OpenCode و Cline و Windsurf و OpenAI CLI Replicas.
  • 8. أداة التدقيق ومؤشرات الأداء (Auditor & KPIs): لوحة تحكم تفاعلية لتدقيق بيئة العمل مع أشرطة تقدم لحظية، حساب نسب الحوكمة المئوية، ومصفوفة جاهزية البوابات، وفحص مخططات البيانات.
الاختصارات العامة: F1 المساعدة • F2 التبديل بين العربية والإنجليزية • F10 / Ctrl+Q الخروج • Tab التنقل بين العناصر.

ز. tasleemat audit (التدقيق الحوكمي والتحقق الهيكلي)

أداة التدقيق المنضبطة للتحقق من امتثال أي بيئة عمل للمشروع وفق مستويات الحوكمة (المستوى 1 أو 2 أو 3) وحزمة المنهجية، مع حساب نسب الإنجاز المئوية وفحص سلامة مخططات البيانات JSON Schema (Draft 2020-12)، وتصدير تقارير JSON لأنظمة CI/CD. 

# تدقيق مجلد المشروع الحالي مع الكشف التلقائي عن المستوى والمنهجية
tasleemat audit

# تدقيق مجلد محدد مع فرض الفحص الصارم لاختبارات خطوط الإنتاج CI/CD
tasleemat audit ./projects/PRJ-2026-CLOUD --tier 2 --pack agile --strict

# استخراج تقرير التدقيق بصيغة JSON المعيارية
tasleemat audit ./my_workspace --json --out audit_report.json

3. أدلة تطبيقية عملية خطوة بخطوة (Tutorials)

الدليل 1: تجهيز بيئة عمل متكاملة لمشروع مؤسسي من الصفر

خطوات عملية لبناء بيئة عمل معتمدة لمشروع رعاية صحية رقمي استراتيجي:

  1. استكشاف التسليمات المطلوبة: نفذ أمر tasleemat list --tier 1 --pack hybrid لمعاينة الـ 42 تسليمة المقررة.
  2. تهيئة مجلد المشروع: نفذ أمر التهيئة الآلي: 
    tasleemat init \
  --tier 1 \
  --pack hybrid \
  --lang ar \
  --code "PRJ-2026-MED" \
  --name "منصة السجلات الطبية الوطنية الموحدة" \
  --pm "د. مريم الغامدي" \
  --sponsor "اللجنة التوجيهية للتحول الرقمي" \
  --out ./PRJ-2026-MED
  3. معاينة هيكلية المجلدات المولدة: ادخل إلى مجلد ./PRJ-2026-MED وستجد: 
    PRJ-2026-MED/
├── manifest.json                  # فهرس المشروع وقيم بصمات SHA-256 للملفات
├── 01_Initiation/
│   ├── PMO-03.01_Project_Charter/
│   │   ├── template.md            # قالب Markdown مع وسوم الأقواس الحاصرة
│   │   ├── guide.md               # دليل الممارس وإرشادات المسؤوليات RACI
│   │   ├── example.md             # مثال واقعي متكامل ومكتمل البيانات
│   │   ├── schema.json            # مخطط JSON Draft 2020-12 للتحقق الآلي
│   │   └── dictionary.csv         # قاموس الحقول المعياري وأنواع البيانات
│   └── PMO-03.02_Stakeholder_Register/
└── ...
  4. توليد مسودة ميثاق المشروع من محضر الاجتماع: 
    tasleemat generate \
  --form PMO-03.01 \
  --notes ./meeting_minutes.txt \
  --lang ar \
  --out ./PRJ-2026-MED/01_Initiation/PMO-03.01_Project_Charter/template.md

الدليل 2: التشغيل في البيئات الحكومية والمصرفية المعزولة (Air-Gapped)

للبيئات فائقة الأمان التي تمنع الاتصال بالإنترنت الخارجي منعاً باتاً:

  1. نقل حزمة التثبيت: انسخ ملف tasleemat-2.5.0.post1-py3-none-any.whl إلى الخادم المعزول عبر وسائط آمنة ومعتمدة.
  2. التثبيت دون اتصال بالإنترنت: 
    pip install --no-index --find-links . tasleemat-2.5.0.post1-py3-none-any.whl
  3. توجيه الأداة لخادم ذكاء اصطناعي محلي: 
    tasleemat config set --provider ollama --model llama3.2 --endpoint "http://10.0.50.12:11434"
  4. التحقق من انعدام حركة البيانات الخارجية: نفذ tasleemat test -v لتأكيد نجاح كافة الاختبارات بدون أي اتصال بالإنترنت.

الدليل 3: أتمتة تهيئة محفظة مشاريع كاملة عبر سكربت Bash

سكربت متقدم لقراءة سجل محفظة المشاريع من ملف CSV وإنشاء كافة بيئات العمل دفعة واحدة: 

#!/usr/bin/env bash
# provision_portfolio.sh - سكربت تهيئة محفظة المشاريع المؤسسية
set -euo pipefail

CSV_FILE="portfolio_registry.csv"
OUTPUT_ROOT="./enterprise_pmo_workspaces"

mkdir -p "$OUTPUT_ROOT"

echo "جاري قراءة المشاريع من ملف $CSV_FILE..."
# تنسيق الملف: code,name,tier,pack,lang,pm,sponsor
tail -n +2 "$CSV_FILE" | while IFS=',' read -r code name tier pack lang pm sponsor; do
    echo "=========================================================="
    echo "جاري إنشاء مشروع: [$code] $name (المستوى $tier، الحزمة $pack)..."
    
    tasleemat init \
      --code "$code" \
      --name "$name" \
      --tier "$tier" \
      --pack "$pack" \
      --lang "$lang" \
      --pm "$pm" \
      --sponsor "$sponsor" \
      --out "$OUTPUT_ROOT/$code" \
      --force
      
    echo "تم بنجاح إنشاء مجلد: $OUTPUT_ROOT/$code"
done

echo "اكتملت تهيئة المحفظة بالكامل بنجاح!"

4. خطوط الأتمتة وأدوات Git

أ. خطاف التحقق التلقائي قبل الالتزام (Git Pre-Commit Hook)

ضع هذا السكربت في .git/hooks/pre-commit لمنع إيداع أي تسليمات معطوبة أو غير مطابقة: 

#!/usr/bin/env bash
# .git/hooks/pre-commit
echo "[Tasleemat Hook] التحقق من سلامة وثائق المشروع..."

# تشغيل الاختبارات الآلية
if ! tasleemat test > /dev/null 2>&1; then
    echo "خطأ: فشلت اختبارات التحقق من الوثائق! تم إيقاف الالتزام."
    exit 1
fi

echo "[Tasleemat Hook] تم التحقق بنجاح، يمكنك المتابعة."
exit 0

ب. استخراج وتحليل الفهرس عبر jq

# استخراج رموز وأسماء تسليمات المرحلة 03 باللغة العربية
tasleemat list --phase 03 --json | jq -r '.[] | "\(.id): \(.name_ar)"'

# عد التسليمات المخصصة للمستوى 3
tasleemat list --tier 3 --json | jq 'length'
