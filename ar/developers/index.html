مرجع المطورين وهندسة الذكاء الاصطناعي

المرجع التقني الشامل لمهندسي البرمجيات، معماريي الذكاء الاصطناعي، ومسؤولي عمليات DevOps. دليل برمجي متكامل لربط تسليمات عبر مكتبة بايثون، أدوات سطر الأوامر (CLI)، خادم بروتوكول سياق النماذج (MCP)، وأسراب الوكلاء الأذكياء متعددي المهام (Multi-Agent Swarms).

1. التثبيت السريع ومتطلبات البيئة

مستودع PyPI الرسمي

حزمة tasleemat منشورة رسميًا عبر مستودع PyPI العام كحزمة بايثون نقية تدعم إصدارات بايثون 3.9 و 3.10 و 3.11 و 3.12 و 3.13. تحتوي الحزمة الموزعة على كافة قوالب التسليمات الـ 114 باللغتين، مخططات JSON المرافقة، قواميس الحقول، أداة سطر الأوامر، وخادم بروتوكول MCP. 

# التثبيت المباشر عبر مدير الحزم pip
pip install tasleemat

# أو التثبيت داخل بيئة افتراضية منعزلة
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install tasleemat

التحقق من جاهزية أداة الطرفية وخادم بروتوكول سياق النموذج (MCP): 

tasleemat --version
tasleemat-mcp --help

2. مرجع أوامر الطرفية الكامل (CLI Reference)

توفر أداة tasleemat في سطر الأوامر إمكانيات متطورة لتأسيس مساحات العمل، واستعراض الفهرس، وتوليد الوثائق بنماذج الذكاء الاصطناعي، وتنفيذ الاختبارات، وتشغيل خوادم الوكلاء الأذكياء.

أ. تأسيس مساحة عمل المشروع المخصصة (tasleemat init)

بناء هيكل مجلدات متكامل منسوخ مسبقاً بالتسليمات الإلزامية حسب فئة الحوكمة وباقة المنهجية: 

# النمط التفاعلي (يطرح أسئلة الإعداد خطوة بخطوة)
tasleemat init

# النمط المباشر للسكربتات: الفئة 2 (متوسطة) مع باقة أجايل بالعربية
tasleemat init   --tier 2   --pack agile   --lang ar   --code "PRJ-2026-CLOUD-01"   --name "مشروع التحول السحابي المؤسسي"   --pm "سارة الأحمد"   --sponsor "د. خالد المنصور"   --out ./workspaces/PRJ-2026-CLOUD-01

# مشروع الفئة 1 الكبرى باللغتين العربية والإنجليزية
tasleemat init   --tier 1   --pack hybrid   --lang both   --code "PRJ-2026-CORE"   --name "Enterprise Core Banking Migration"   --pm "Tariq Al-Harbi"   --sponsor "Executive VP IT"   --out ./enterprise_workspace

ب. استعراض الفهرس والبحث المتقدم (tasleemat list & search)

استعراض المخرجات الـ 114 باللغتين العربية والإنجليزية أو البحث السريع بالكلمات المفتاحية: 

# استعراض كافة التسليمات بالعربية أو الإنجليزية
tasleemat list --lang ar
tasleemat list --lang en

# البحث السريع في الفهرس
tasleemat search "مخاطر" --lang ar
tasleemat search "ميثاق" --lang ar
tasleemat search "PMO-03.01" --lang en

ج. إدارة حسابات الذكاء الاصطناعي (tasleemat config)

حفظ المفاتيح في المسار الآمن ~/.tasleemat/config.json: 

# ضبط مزود Google Gemini
tasleemat config set --provider gemini --model gemini-2.5-flash --key "AIzaSy..."

# ضبط مزودي OpenAI أو Anthropic
tasleemat config set --provider openai --model gpt-4o --key "sk-proj-..."
tasleemat config set --provider anthropic --model claude-3-5-sonnet-20241022 --key "sk-ant-..."

# ضبط خادم Ollama المحلي المستقل
tasleemat config set --provider ollama --model llama3.2 --endpoint "http://localhost:11434"

# استعراض الإعدادات الحالية بأمان
tasleemat config show

د. التوليد الآلي للوثائق (tasleemat generate)

توليد مسودات احترافية من ملاحظات الاجتماعات باستخدام الذكاء الاصطناعي: 

# توليد ميثاق المشروع (PMO-03.01) من ملف ملاحظات الاجتماع
tasleemat generate   --form PMO-03.01   --notes ./meeting_minutes.txt   --lang ar   --out ./drafts/ميثاق_المشروع.md

# نمط المحاكاة المحلي (Mock) لخطوط CI دون استهلاك رموز API
tasleemat generate   --form PMO-03.01   --notes "ملاحظات تجريبية"   --mock   --out ./ci_output/Mock_Charter.md

هـ. حزمة الاختبارات الآلية (tasleemat test)

# تنفيذ كافة اختبارات الوحدة والتكامل (أكثر من 140 اختباراً)
tasleemat test -v

3. معمارية مكتبة بايثون البرمجية (SDK Reference)

تصدّر مكتبة tasleemat ثماني دوال برمجية محورية لاستكشاف الفهرس، واستخراج الأصول، وتحليل التخصيص، والتحقق الصارم من التنسيقات، وتصيير الوثائق إلى صفحات HTML مستقلة.

الدالة البرمجية المعاملات المدخلة نوع المخرجات الوصف الوظيفي
list_artifacts() phase=None, tier=None, pack=None List[ArtifactSummary] استرجاع كائنات ملخصة لكافة الـ 114 تسليمة أو باقة مخصصة مع بصمات SHA-256 الرقمية.
get_artifact_definition() artifact_id: str dict قاموس البيانات الوصفية المعتمد متضمناً المرحلة وفئات الحوكمة ومسارات الأصول.
get_artifact_assets() artifact_id: str, lang='en' ArtifactAssets كائن برمجي لإدارة مسارات الملفات واسترجاع المحتويات بأمان دون اختراق المسارات.
get_artifact_asset() artifact_id: str, role: str, lang='en' Union[str, dict, list] استخراج محتوى الأصل مباشرة بحسب دوره: template، guide، prompt، schema، dictionary، example.
get_tailoring_profile() tier: str, pack: str='general' List[str] تحديد قائمة معرفات التسليمات الإلزامية لمستوى الحوكمة (1, 2, 3) وباقة المنهجية.
get_lexicon() category: Optional[str]=None List[dict] استرجاع المصطلحات المعتمدة المترجمة بين العربية والإنجليزية وفق معايير PMI وهيئة الحكومة الرقمية (DGA).
validate_artifact_data() artifact_id: str, data: dict, mode='strict' ValidationReport التحقق الصارم من كائن البيانات مقابل مخطط Draft 2020-12 وتنسيقات RFC المعتمدة.
render_artifact() artifact_id: str, lang='en', data=None, out_path=None str تصيير قالب التسليمة وبياناتها إلى صفحة HTML أنيقة جاهزة للطباعة مع دعم الاتجاه العربي (RTL).

مثال تطبيقي متكامل في بايثون

import tasleemat

# 1. استخراج التسليمات الإلزامية لمشروع قياسي (فئة 2) يتبع المنهجية الرشيقة
required_ids = tasleemat.get_tailoring_profile(tier="2", pack="agile")
print(f"عدد التسليمات الإلزامية: {len(required_ids)}")

# 2. استخراج موجه الذكاء الاصطناعي المعتمد لميثاق المشروع (PMO-03.01) بالعربية
prompt_ar = tasleemat.get_artifact_asset("PMO-03.01", role="prompt", lang="ar")

# 3. قراءة مخطط JSON الهيكلي
schema_def = tasleemat.get_artifact_asset("PMO-03.01", role="schema", lang="ar")
print(f"معرف المخطط: {schema_def.get('$id')}")

# 4. التدقيق البرمجي في بيانات الميثاق (النمط الصارم)
charter_payload = {
    "project_code": "PRJ-2026-CLOUD",
    "project_name": "مشروع التحول السحابي الموحد",
    "start_date": "2026-11-01",              # تاريخ صالح وفق مواصفة RFC 3339
    "sponsor_name": "د. خالد المنصور",
    "estimated_budget": 3500000.00
}

report = tasleemat.validate_artifact_data("PMO-03.01", charter_payload, mode="strict")
if report.valid:
    print(f"✅ البيانات مطابقة للمخطط! بصمة التحقق: {report.fingerprint}")
else:
    print(f"❌ فشل التدقيق لوجود {len(report.errors)} أخطاء:")
    for err in report.errors:
        print(f"   • {err.field_path}: {err.message} (الرمز: {err.code})")

# 5. تصيير الوثيقة المعتمدة إلى صفحة HTML مطبوعة بالعربية
html_output = tasleemat.render_artifact(
    artifact_id="PMO-03.01",
    lang="ar",
    data={"Project_Name": "مشروع التحول السحابي", "Project_Code": "PRJ-2026-CLOUD"},
    out_path="./exports/charter_rendered.html"
)

4. بروتوكول سياق النماذج (MCP) للذكاء الاصطناعي

قنوات Stdio JSON-RPC 2.0

تتضمن تسليمات خادم بروتوكول Model Context Protocol قياسي متوافق مع مواصفة 2024-11-05. يتيح الخادم لعملاء الذكاء الاصطناعي (مثل Claude Desktop، Cursor، OpenCode، و Antigravity) استكشاف الفهرس، وجلب القوالب والموجهات، والبحث في المصطلحات، والتحقق الصارم من مخططات JSON، وتصيير صفحات HTML برمجياً.

ملفات إعدادات العملاء الذكية

أضف خادم تسليمات إلى ملف إعدادات العميل الخاص بك:

  • Claude Desktop: ~/.config/Claude/claude_desktop_config.json (لينكس) أو المسار الموازي في ماك وويندوز
  • محرر Cursor: الملف .cursor/mcp.json في جذر مساحة العمل
  • مساعدات OpenCode و Antigravity: تشغيل الأمر المباشر tasleemat mcp أو tasleemat-mcp
// claude_desktop_config.json أو .cursor/mcp.json
{
  "mcpServers": {
    "tasleemat": {
      "command": "tasleemat",
      "args": ["mcp"]
    }
  }
}

أدوات MCP الست الأساسية المتاحة للوكلاء

اسم الأداة في MCP المعاملات المدخلة وظيفة الأداة للوكيل الذكي
tasleemat_list_artifacts phase?: string, tier?: string استكشاف التسليمات الإلزامية المتاحة عبر مراحل المشروع الثماني.
tasleemat_get_artifact artifact_id: string استرجاع البيانات الوصفية وبصمات SHA-256 للمخرج المحدد.
tasleemat_get_asset artifact_id: string, role: string, lang?: "en"|"ar" جلب نصوص template أو guide أو prompt أو schema أو dictionary أو example.
tasleemat_get_lexicon category?: string, query?: string منع الانحراف الدلالي في الترجمة عبر استرجاع المصطلحات الرسمية المعتمدة من PMI و DGA.
tasleemat_validate_data artifact_id: string, data: object, mode?: "strict"|"draft" التحقق الهيكلي من صحة كائن البيانات؛ وإرجاع قائمة أخطاء برمجية دقيقة في حال عدم المطابقة.
tasleemat_render_artifact artifact_id: string, lang?: "en"|"ar", data?: object تصيير الوثيقة المعتمدة كصفحة HTML مستقلة للعرض على لجان التوجيه والرعاة التنفيذيين.

5. مخططات Draft 2020-12 والتحقق الصارم من معايير RFC

كل تسليمة من الـ 114 تسليمة مقترنة بمخطط JSON رسمي متوافق مع مواصفة JSON Schema Draft 2020-12. وبينما تعد قيود التنسيق اختيارية في المواصفة العامة، يفرض محرك التدقيق في تسليمات التحقق الصارم في نمط التوكيد (Assertion Mode) لضمان عقود بيانات لا تقبل الشك أو التخمين.

تنسيقات RFC المعتمدة في محرك التحقق

محدد التنسيق المعيار القياسي شروط التحقق والحالات المستثناة
date RFC 3339 full-date الصيغة الصارمة YYYY-MM-DD. التحقق من سلامة الأيام والشهور وسنوات الكبيس (رفض 29 فبراير في السنوات البسيطة).
date-time RFC 3339 date-time يشترط التاريخ وفاصل T والوقت وتحديد النطاق الزمني (Z أو +/-HH:MM). يدعم ثانية الكبيس 60.
time RFC 3339 partial-time صيغة الوقت القياسية HH:MM:SS[.fractional][Z|offset].
uuid RFC 4122 UUID الصيغة السداسية العشرية 8-4-4-4-12 (36 حرفاً). المعرفات المجردة فقط؛ بادئات URN تنتمي لـ uri.
uri RFC 3986 URI عنوان مطلق يشترط وجود المخطط (مثل https://). يمنع المسافات والمحارف غير المرمزة.
uri-reference RFC 3986 URI Reference يقبل العنوان المطلق أو المسار النسبي المنضبط دون مسافات فارغة.
email RFC 5322 addr-spec الصيغة القياسية user@domain بحد أقصى 254 بايت مع فحص النطاقات.
duration ISO 8601 / RFC 3339 نصوص المدة الزمنية القياسية (مثل P1Y2M، PT15M). يرفض الرموز المجردة أو النصوص الوصفية.

النمط الصارم (Strict) مقابل نمط المسودة (Draft)

🔒 النمط الصارم (Strict Mode)

يفرض كافة الحقول الإلزامية، أمان الأنواع (التفريق بين True و 1)، الحدود الرقمية، وتنسيقات RFC. يُرجع valid=False عند أي مخالفة، ويُستخدم في بوابات العبور واختبارات CI/CD.

📝 نمط المسودة (Draft Mode)

يسمح بالملفات غير المكتملة والحقول الناقصة مع إطلاق تحذيرات برمجية غير حاجبة. مخصص لمساعدة الوكلاء الأذكياء على صياغة الأقسام تدريجياً عبر حوارات متعددة.

6. حلقة التصحيح الذاتي التلقائي للوكلاء الأذكياء

عند توليد كائنات البيانات بواسطة النماذج اللغوية، تقع أخطاء شائعة (مثل صياغة التواريخ بصيغة غير قياسية، أو تمرير القيم المنطقية كنصوص). يعمل محرك الفحص في تسليمات كـ مترجم برمجي عالي الدقة يُعيد تفاصيل الخطأ الدقيقة للنموذج ليعيد صياغته ذاتياً حتى المطابقة التامة.

flowchart TD RAW["مدخلات المشروع: ملاحظات الاجتماعات"] --> LLM["وكيل الذكاء الاصطناعي (Gemini / Claude / GPT)"] LLM --> JSON["مسودة كائن البيانات JSON"] JSON --> VALIDATE{"tasleemat.validate_artifact_data(strict=True)"} VALIDATE -->|مطابق: valid == True| RENDER["tasleemat.render_artifact()"] RENDER --> HUMAN["اعتماد بوابة العبور من راعي المشروع"] VALIDATE -->|غير مطابق: valid == False| SURGICAL["استخراج مصفوفة الأخطاء الهيكلية:
- مسار الحقل: start_date
- رمز الخطأ: FORMAT_VIOLATION
- القاعدة: معيار RFC 3339 (YYYY-MM-DD)"] SURGICAL --> REPROMPT["إعادة توجيه النموذج بالأخطاء المحددة فقط"] REPROMPT --> LLM

شيفرة حلقة التصحيح الذاتي في بايثون

import tasleemat
from tasleemat.ai import AIClient

def generate_and_heal_deliverable(artifact_id: str, raw_notes: str, max_attempts: int = 3) -> dict:
    client = AIClient(provider="gemini", model="gemini-2.5-flash")
    schema_def = tasleemat.get_artifact_asset(artifact_id, role="schema", lang="ar")
    prompt_instructions = tasleemat.get_artifact_asset(artifact_id, role="prompt", lang="ar")
    
    system_prompt = (
        f"أنت مهندس ذكاء اصطناعي متخصص في PMO. قم بتوليد كائن JSON صالح يطابق مخطط Draft 2020-12 تماماً.\n"
        f"معرف المخطط: {schema_def.get('$id')}\n"
        f"يتم فرض قيود RFC الصارمة: التواريخ بصيغة YYYY-MM-DD والأرقام موجبة."
    )
    
    current_prompt = f"{prompt_instructions}\n\nملاحظات المشروع:\n{raw_notes}"
    
    for attempt in range(1, max_attempts + 1):
        raw_response = client.generate(prompt=current_prompt, system_instruction=system_prompt)
        payload = extract_json_block(raw_response)
        
        # الفحص البرمجي الصارم
        report = tasleemat.validate_artifact_data(artifact_id, payload, mode="strict")
        if report.valid:
            print(f"✅ تم اجتياز الفحص بنجاح في المحاولة {attempt}!")
            return payload
            
        print(f"⚠️ المحاولة {attempt} غير مطابقة. تجميع التغذية العكسية الدقيقة...")
        error_context = "\n".join([f"- الحقل '{e.field_path}': {e.message} (القاعدة: {e.schema_rule})" for e in report.errors])
        
        # إعادة التوجيه الدقيق بالأخطاء فقط
        current_prompt = (
            f"مخرجات JSON السابقة احتوت على أخطاء هيكلية محددة:\n{error_context}\n\n"
            f"قم بتصحيح هذه الحقول فقط وأعد توليد كائن JSON صالح بدون مقدمات أو تعليقات."
        )
        
    raise RuntimeError(f"تعذر استيفاء المخطط للتسليمة {artifact_id} بعد {max_attempts} محاولات.")

7. معمارية أسراب الوكلاء المتعددين (Multi-Agent PMO Swarms)

في بيئات المؤسسات المتقدمة التي تستخدم أطر CrewAI أو LangGraph أو AutoGen، يتم توزيع مهام التوثيق والحوكمة على وكلاء متخصصين متعددي المهام بدلاً من الاعتماد على وكيل أحادي.

الأدوار التخصصية في السرب الذكي

1. الوكيل المنسق العام (مدير PMO الافتراضي)

المسؤولية: استدعاء get_tailoring_profile(tier, pack) لتحديد المخرجات المطلوبة، وفرض مخطط الاعتماديات (DAG) بحيث لا يبدأ إعداد WBS قبل اعتماد الميثاق.

صلاحيات الأدوات: tasleemat_list_artifacts, tasleemat_get_artifact, get_tailoring_profile

2. وكلاء الصياغة التخصصية (تحليل الأعمال، الجدولة، المخاطر)

المسؤولية: صياغة الأقسام بالاستناد إلى موجهات get_artifact_asset(role="prompt") والاسترشاد بالأمثلة الواقعية الـ 228 في examples/ar/.

صلاحيات الأدوات: tasleemat_get_asset, tasleemat_get_lexicon

3. وكيل التدقيق الحوكمي (QA & Governance Gatekeeper)

8. عميل الذكاء الاصطناعي الموحد في بايثون (tasleemat.ai)

توفر فئة tasleemat.ai.AIClient واجهة بايثون موحدة تدعم نماذج Google Gemini، OpenAI، Anthropic، خوادم Ollama المحلية، ونمط المحاكاة المكتبي (Mock) لاختبارات التكامل.

رمز المزود النموذج الافتراضي نوع نقطة الاتصال المدعومة متغير البيئة القياسي
gemini gemini-2.5-flash Google AI Studio Cloud REST API GEMINI_API_KEY
openai gpt-4o OpenAI API أو وكيل مخصص (api_base) OPENAI_API_KEY
anthropic claude-3-5-sonnet-20241022 Anthropic Messages API ANTHROPIC_API_KEY
ollama llama3.2 نقطة اتصال محلية مستقلة (http://localhost:11434) OLLAMA_HOST
mock mock-v1 محاكاة حتمية داخل الذاكرة لخطوط CI بدون (صفر استهلاك)

نموذج استخدام عميل الذكاء الاصطناعي في بايثون

from tasleemat.ai import AIClient
import tasleemat

# تهيئة العميل البرمجي (يقرأ المفتاح تلقائياً من الإعدادات أو البيئة)
client = AIClient(provider="gemini", model="gemini-2.5-flash")

# جلب موجه بيان النطاق المعتمد (PMO-04.02.05)
prompt_text = tasleemat.get_artifact_asset("PMO-04.02.05", role="prompt", lang="ar")

notes = '''
المشروع: منصة معالجة البيانات المركزية
المخرجات الأساسية: محرك استيعاب البيانات، عنقود كافكا للبث اللحظي، مستودع البيانات السحابي، لوحات PowerBI.
الاستثناءات: تفكيك الأجهزة القديمة غير مشمول في هذا النطاق.
معايير القبول: جاهزية بنسبة 99.9%، وزمن استجابة الاستيعاب أقل من 5 ثوانٍ.
'''

# توليد مسودة الوثيقة بصيغة ماركداون
deliverable_md = client.generate(
    prompt=f"{prompt_text}\n\nملاحظات المشروع:\n{notes}",
    system_instruction="أنت مدير مكتب إدارة مشاريع محترف. قم بصياغة بيان نطاق متكامل ومطابق لهيكل النموذج."
)

print(deliverable_md)

9. خطوط أنابيب CI/CD وبوابات الجودة المؤتمتة

تطبيق فلسفة الوثائق كشيفرة برمجية (Docs-as-Code) عبر دمج بوابات فحص تسليمات داخل خطوط الأنابيب في Git، لمنع دمج أي وثائق غير مطابقة للمخططات في الفروع الرئيسية.

ملف إعدادات GitHub Actions (.github/workflows/pmo-governance.yml)

name: PMO Governance & Schema Quality Gates

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  validate-governance:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"
          cache: "pip"

      - name: Install Tasleemat
        run: |
          pip install --upgrade pip
          pip install tasleemat

      - name: Validate Completed Artifact JSON Files
        run: |
          # فحص كافة ملفات JSON للمشروع مقابل مخططات Draft 2020-12
          python3 -c "
          import pathlib, sys, json, tasleemat
          errors = 0
          for p in pathlib.Path('workspaces').rglob('*.json'):
              art_id = p.stem.split('.')[0]
              if art_id.startswith('PMO-'):
                  data = json.loads(p.read_text(encoding='utf-8'))
                  report = tasleemat.validate_artifact_data(art_id, data, mode='strict')
                  if not report.valid:
                      print(f'❌ فشل التدقيق للملف {p}: {report.errors}')
                      errors += 1
          if errors > 0:
              sys.exit(1)
          print('✅ اجتازت كافة وثائق المشروع بوابات الجودة الصارمة بنجاح!')
          "

      - name: Run Test Suite
        run: |
          tasleemat test -v

10. عقود الحسابات الرياضية الموثقة (Attested Math Contracts)

تحليل القيمة المكتسبة PMO-06.05

تتعرض النماذج اللغوية للهلوسة عند إجراء العمليات الحسابية والمالية التراكمية. تؤسس تسليمات عقود حسابات رياضية موثقة وحتمية بحيث تُحسب مؤشرات الأداء المالي برمجياً دون تدخل الوكلاء، ويتم التحقق منها قبل تقديمها لبوابة الاعتماد.

عقد حسابات تحليل القيمة المكتسبة (PMO-06.05 EVA)

المؤشر المالي المعادلة القياسية قاعدة التقريب الحتمية المعتمدة
تباين الجدول الزمني (SV) SV = EV - PV تطابق عشري دقيق للعملة (نسبة تفاوت ± 0.01)
تباين التكلفة (CV) CV = EV - AC تطابق عشري دقيق للعملة (نسبة تفاوت ± 0.01)
مؤشر أداء الجدول (SPI) SPI = EV / PV تقريب نصف لأعلى إلى خانتين عشريتين (قيمة 0.0 عند انعدام PV)
مؤشر أداء التكلفة (CPI) CPI = EV / AC تقريب نصف لأعلى إلى خانتين عشريتين (قيمة 0.0 عند انعدام AC)
التقدير عند الاكتمال (EAC) EAC = BAC / CPI تقريب نصف لأعلى إلى خانتين عشريتين
مؤشر الأداء المتبقي (TCPI) TCPI = (BAC - EV) / (BAC - AC) تقريب نصف لأعلى إلى خانتين عشريتين

عند توليد تقارير القيمة المكتسبة عبر الوكلاء الأذكياء، يستدعي خط الأنابيب الأداة المعتمدة tools/attested_computations/eva_calculator.py لإنتاج الحقائق الرياضية بدقة متناهية، وتقوم أداة التدقيق eva_attester.py بالتحقق التام من مطابقة الأرقام في المستند للحقائق الرياضية قبل الاعتماد المؤسسي.
