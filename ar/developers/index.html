بوابة المطورين وهندسة الذكاء الاصطناعي

المرجع التقني الشامل لمهندسي البرمجيات، معماريي الذكاء الاصطناعي، ومسؤولي عمليات DevOps. دليل برمجي متكامل لربط تسليمات عبر مكتبة بايثون، أدوات سطر الأوامر (CLI)، خادم بروتوكول سياق النماذج (MCP)، وأسراب الوكلاء الأذكياء متعددي المهام (Multi-Agent Swarms).

الأقسام الفنية: 📖 بوابة المطورين⌨️ أداة الطرفية والأتمتة🐍 مكتبة بايثون (SDK)🔌 خادم بروتوكول MCP📐 المخططات والتحقق🤖 أسراب الوكلاء و CI/CD

1. التثبيت السريع ومتطلبات بيئة العمل

PyPI: tasleemat

حزمة تسليمات منشورة عبر مستودع PyPI الرسمي كحزمة بايثون خالصة (zero-dependency) تدعم إصدارات بايثون 3.9 و 3.10 و 3.11 و 3.12 و 3.13. تتضمن التوزيعة كافة قوالب التسليمات الـ 114 ثنائية اللغة، ومخططات JSON المرافقة، وقواميس CSV، وأداة سطر الأوامر (CLI)، وخادم بروتوكول سياق النماذج (MCP). 

# التثبيت المباشر عبر مدير الحزم pip
pip install tasleemat

# التحقق من نجاح التثبيت وأدوات التشغيل
tasleemat --version
tasleemat-mcp --help

2. مرجع أوامر الطرفية (CLI)

الصفحة المخصصة لأداة الطرفية ←

تهيئة بيئات العمل المخصصة (tasleemat init)، البحث في فهرس التسليمات باللغتين العربية والإنجليزية (tasleemat search)، إدارة مفاتيح النماذج اللغوية بأمان (tasleemat config)، توليد الوثائق آلياً (tasleemat generate)، وتشغيل حزم الاختبارات الداخلية (tasleemat test). 

tasleemat init --tier 2 --pack agile --lang ar --code "PRJ-CLOUD" --name "مشروع السحابة" --out ./prj

3. معمارية مكتبة بايثون (SDK)

الصفحة المخصصة لمكتبة بايثون ←

مكتبة بايثون خالصة تصدّر 8 دوال معتمدة: list_artifacts و get_artifact_definition و get_artifact_assets و get_artifact_asset و get_tailoring_profile و validate_artifact_data و get_lexicon و render_artifact. 

import tasleemat
profile = tasleemat.get_tailoring_profile(tier=2, pack="agile")
report = tasleemat.validate_artifact_data("PMO-03.01", {"project_id": "PRJ-01"}, mode="draft")

4. خادم بروتوكول سياق النماذج (MCP)

الصفحة المخصصة لخادم MCP ←

خادم stdio قياسي ببروتوكول JSON-RPC 2.0 يتيح 6 أدوات متخصصة لبيئات Claude Desktop و Cursor والوكلاء الأذكياء: tasleemat_list_forms و tasleemat_get_form و tasleemat_get_schema و tasleemat_validate و tasleemat_tailor_project و tasleemat_calculate_eva. 

# تشغيل خادم بروتوكول MCP
tasleemat-mcp

5. مخططات JSON وتنسيقات RFC المعيارية

الصفحة المخصصة للمخططات والتحقق ←

تقترن كافة الـ 114 تسليمة بمخططات JSON متوافقة بدقة مع معيار JSON Schema Draft 2020-12. يتم فرض قيود التنسيق الصارمة لـ RFC 3339 (التواريخ والأوقات)، RFC 4122 (معرفات UUID)، RFC 3986 (الروابط)، و RFC 5322 (البريد الإلكتروني).

6. حلقة التصحيح الذاتي التلقائي للوكلاء الأذكياء

قراءة دليل التصحيح الذاتي ←

الوكلاء الأذكياء لا يخمنون: عندما تولد النماذج اللغوية بيانات JSON غير صحيحة، ترجع دالة tasleemat.validate_artifact_data مسار الخطأ المحدد بدقة (JSON Pointer). يقوم الوكيل بدمج رسالة الخطأ في أمره التالي لإصلاح البيانات تلقائياً.

7. أسراب الوكلاء متعددي المهام (Multi-Agent Swarm)

قراءة دليل أسراب الوكلاء ←

تنسيق أدوار الذكاء الاصطناعي المتخصصة (مدير المشروع، مدقق الحوكمة، مسؤول المخاطر والأخلاقيات، الراعي التنفيذي) باستخدام أطر مثل CrewAI و LangGraph مع الحفاظ على الحدود الصارمة لمراجعة واعتماد العنصر البشري قبل بوابات المراحل.

8. التوليد البرمجي عبر tasleemat.ai.AIClient

قراءة مرجع AIClient ←

استخدام واجهة tasleemat.ai.AIClient الموحدة لتوليد مسودات الوثائق عبر Google Gemini و OpenAI GPT-4o و Anthropic Claude و DeepSeek مع بناء وتجميع موحد للأوامر.

9. خطوط CI/CD وبوابات الجودة الآلية

قراءة دليل CI/CD ←

دمج تسليمات في GitHub Actions أو GitLab CI لفرض اكتمال التسليمات وصحة المخططات والاتساق ثنائي اللغة آلياً مع كل إيداع برمجي (commit) أو طلب دمج (PR).

10. عقود الحسابات الرياضية الموثقة (PMO-06.05)

قراءة عقود الحسابات ←

تتعرض النماذج اللغوية للهلوسة في الحسابات الدقيقة؛ لذلك يفرض إطار تسليمات محركات حسابية حتمية لتحليل القيمة المكتسبة (EVA في PMO-06.05) ومصفوفات شدة المخاطر لضمان موثوقية المقاييس رياضياً.

تثبيت الحزمة عبر pip: pip install tasleemat
