المسار الأول: ممارسو إدارة المشاريع ومديرو مكاتب الـ PMO

القوالب والحوكمة

لمديري المشاريع، وقادة مكاتب إدارة المشاريع، ومديري التسليم الراغبين في ضبط الحوكمة وتجنب البدء من وثائق فارغة ومواءمة التسليمات مع حجم مخاطر المنظمة.

  1. الخطوة 1 — تحديد مستوى الحوكمة: صنف مشروعك ضمن المستوى 1 (المشاريع الكبرى > 40 مليون ريال)، المستوى 2 (القياسية 4-40 مليون ريال)، أو المستوى 3 (المشاريع الرشيقة < 4 ملايين ريال). راجع دليل تخصيص الحوكمة.
  2. الخطوة 2 — استخراج تسليمات مرحلة البدء: حمّل القوالب التأسيسية بدءاً من PMO-03.01 ميثاق المشروع، وPMO-03.03 سجل الافتراضات، وPMO-03.04 سجل المعنيين.
  3. الخطوة 3 — مراجعة الأدلة التنظيمية الـ 12: اضبط بوابات المراجعة وصلاحيات RACI قبل الانتقال إلى التخطيط التفصيلي في المرحلة 04.

المسار الثاني: الفرق التقنية ومهندسو الأتمتة

مكتبة بايثون وأمر التشغيل CLI

لمطوري البرمجيات، ومهندسي DevOps، ومسؤولي الأتمتة الساعين لدمج تسليمات المشاريع مباشرة ضمن خطوط الـ CI/CD، والتحقق الآلي من جودة البيانات.

  1. الخطوة 1 — تثبيت حزمة بايثون المعتمدة: 
    pip install tasleemat
  2. الخطوة 2 — استعراض التسليمات المخصصة عبر الطرفية: 
    tasleemat list --tier 2 --pack agile
  3. الخطوة 3 — تصدير القوالب والتحقق من البيانات: 
    tasleemat asset PMO-04.14 template --lang ar > risk_plan_ar.md
tasleemat validate PMO-04.14 completed_data.json

المسار الثالث: مساعدو الذكاء الاصطناعي والأنظمة متعددة الوكلاء

بروتوكول سياق النماذج (MCP)

للفرق التي تستخدم مساعدي الذكاء الاصطناعي (Claude Desktop، Cursor، Antigravity) أو تبني أنظمة وكلاء متعددة لصياغة وتدقيق وثائق الحوكمة بدقة متناهية.

  1. الخطوة 1 — ضبط إعدادات خادم MCP: أضف خادم Tasleemat MCP إلى إعدادات العميل لديك: 
    {
  "mcpServers": {
    "tasleemat": {
      "command": "tasleemat",
      "args": ["mcp"]
    }
  }
}
  2. الخطوة 2 — جلب الأصول المرجعية بدقة: وجّه نموذج الذكاء الاصطناعي لاسترجاع الموجه (Prompt) والدليل ومخطط Draft 2020-12 عبر أداة get_artifact_asset لمنع الهلوسة في هيكلة الوثائق.
  3. الخطوة 3 — حلقة التصحيح الذاتي المغلقة: أرسل البيانات المصوغة لأداة validate_artifact_data، وفي حال وجود أخطاء بنوية يتم إرجاع مسار الخطأ للنموذج لتصحيحه ذاتياً قبل التوقيع البشري.
