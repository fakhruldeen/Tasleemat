## Reporting a Vulnerability

The Tasleemat team takes security seriously. If you discover a security vulnerability or sensitive data issue within the repository, please report it responsibly:

1. **Do not create a public GitHub Issue.**
2. Send an email to the repository maintainer or open a private security advisory via GitHub.
3. Include detailed steps to reproduce the issue.

We will acknowledge receipt within 48 hours and coordinate a timely fix.
