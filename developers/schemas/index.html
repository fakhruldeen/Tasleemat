JSON Schemas & Autonomous Healing

Strict validation contracts across 114 deliverables, RFC format enforcement, and the autonomous self-correction loop for AI agents.

Draft 2020-12 Dialect & Specification

Every canonical deliverable in Tasleemat is paired with a companion JSON schema declaring "$schema": "https://json-schema.org/draft/2020-12/schema". The schemas declare required metadata, nested objects, typed arrays, and strict format validation rules.

Enforced RFC Formats:

  • RFC 3339 (Date & Timestamp): Formats date (YYYY-MM-DD) and date-time (YYYY-MM-DDTHH:MM:SSZ). Leap years and timezone offsets are strictly validated.
  • RFC 4122 (UUID): Format uuid verifying 128-bit identifiers (8-4-4-4-12 hexadecimal structure).
  • RFC 3986 (URI & URI Reference): Formats uri and uri-reference ensuring compliant scheme, authority, and path syntax.
  • RFC 5322 (Email Address): Format email enforcing RFC-compliant user and domain structure.

Validation Modes: Strict vs. Draft

mode="strict" enforces all required fields, non-empty strings, and rejection of undeclared properties. mode="draft" allows progressive elaboration during early project planning stages while verifying types and formats for populated fields.

The Autonomous Agent Self-Correction Feedback Loop

Healing Engine

When an LLM synthesizes structured project data, slight discrepancies can occur (e.g. missing required approval signatures or malformed ISO dates). The agent self-correction feedback loop uses deterministic schema validation to teach the model how to heal its own output in a tight retry loop:

Autonomous Healing Python Script

import tasleemat

def synthesize_with_self_correction(artifact_id: str, prompt_notes: str, max_retries: int = 3):
    schema = tasleemat.get_artifact_asset(artifact_id, "schema", lang="en")
    current_notes = prompt_notes
    
    for attempt in range(1, max_retries + 1):
        # 1. Call your configured LLM (e.g. Gemini, OpenAI, Claude)
        candidate_data = my_llm_call(notes=current_notes, schema=schema)
        
        # 2. Validate against Draft 2020-12 schema
        report = tasleemat.validate_artifact_data(artifact_id, candidate_data, mode="strict")
        if report.valid:
            print(f"Success on attempt {attempt}!")
            return candidate_data
            
        # 3. Formulate targeted healing prompt
        error_messages = [f"- {e.path}: {e.message}" for e in report.errors]
        current_notes = (
            f"{prompt_notes}\n\n"
            f"[CRITICAL: Previous attempt failed validation with errors:]\n"
            + "\n".join(error_messages)
            + "\nFix these exact paths and return valid JSON."
        )
    raise RuntimeError("Failed to converge on valid schema payload within retry limit.")
