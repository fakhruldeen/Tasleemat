1. Installation & Environment Prerequisites

PyPI: tasleemat

Tasleemat is distributed as a zero-dependency, pure-Python package on PyPI, supporting Python 3.9, 3.10, 3.11, 3.12, and 3.13. The core distribution packages all 114 bilingual deliverable templates, JSON companion schemas, CSV data dictionaries, CLI commands, and the Model Context Protocol (MCP) server. 

# Install from PyPI
pip install tasleemat

# Or install within isolated virtual environment
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install tasleemat

Verify that both the core CLI tool and the standalone MCP executable are registered on your PATH: 

tasleemat --version
tasleemat-mcp --help

2. Complete CLI Command Reference

The tasleemat command-line executable provides first-class scaffolding, catalog inspection, LLM generation, automated test execution, and MCP runtime support.

A. Project Workspace Scaffolding (tasleemat init)

Generates a tailored project directory pre-populated with required 5-file deliverable bundles according to governance sizing tier and methodology pack: 

# Interactive wizard mode (prompts for project code, name, PM, sponsor)
tasleemat init

# Non-interactive headless mode: Tier 2 (Standard Enterprise) with Agile Pack in Arabic
tasleemat init   --tier 2   --pack agile   --lang ar   --code "PRJ-2026-CLOUD-01"   --name "منصة التحول الرقمي السحابي"   --pm "سارة الأحمد"   --sponsor "د. خالد المنصور"   --out ./workspaces/PRJ-2026-CLOUD-01

# Enterprise Tier 1 Project in both English and Arabic
tasleemat init   --tier 1   --pack hybrid   --lang both   --code "PRJ-2026-CORE"   --name "Enterprise Core Banking Migration"   --pm "Tariq Al-Harbi"   --sponsor "Executive VP IT"   --out ./enterprise_workspace

B. Catalog Exploration & Search (tasleemat list & search)

Inspect the 114 deliverables or search across English and Arabic artifact titles: 

# List all forms in English or Arabic
tasleemat list --lang en
tasleemat list --lang ar

# Search by keyword or deliverable code
tasleemat search "Risk" --lang en
tasleemat search "ميثاق" --lang ar
tasleemat search "PMO-03.01" --lang en

C. LLM AI Account Configuration (tasleemat config)

Securely store credentials in ~/.tasleemat/config.json without environment variable collision: 

# Configure Google Gemini
tasleemat config set --provider gemini --model gemini-2.5-flash --key "AIzaSy..."

# Configure OpenAI or Anthropic
tasleemat config set --provider openai --model gpt-4o --key "sk-proj-..."
tasleemat config set --provider anthropic --model claude-3-5-sonnet-20241022 --key "sk-ant-..."

# Configure local Ollama endpoint
tasleemat config set --provider ollama --model llama3.2 --endpoint "http://localhost:11434"

# Display active configuration (hides secret keys)
tasleemat config show

D. Automated AI Document Generation (tasleemat generate)

Draft formal deliverables from unstructured kickoff notes using configured AI providers: 

# Generate Project Charter (PMO-03.01) from raw text notes
tasleemat generate   --form PMO-03.01   --notes ./meeting_minutes.txt   --lang en   --out ./drafts/Project_Charter.md

# Offline mock mode for continuous integration (zero API token cost)
tasleemat generate   --form PMO-03.01   --notes "Mock project notes"   --mock   --out ./ci_output/Mock_Charter.md

E. Automated Test Suite (tasleemat test)

# Run complete internal test suite (140+ unit and integration tests)
tasleemat test -v

3. Python SDK Architecture & API Reference

The tasleemat library exports 8 pure-Python functions for catalog discovery, asset loading, tailoring resolution, RFC format validation, and offline document rendering.

Function Parameters Return Type Description
list_artifacts() phase=None, tier=None, pack=None List[ArtifactSummary] Discovers summary objects for all 114 deliverables or tailored subset with SHA-256 fingerprints.
get_artifact_definition() artifact_id: str dict Retrieves canonical metadata dictionary including phase codes, tier mappings, and asset file paths.
get_artifact_assets() artifact_id: str, lang='en' ArtifactAssets Object containing safe file path resolvers and convenience content accessors.
get_artifact_asset() artifact_id: str, role: str, lang='en' Union[str, dict, list] Fetches parsed content directly by role: template, guide, prompt, schema, dictionary, example.
get_tailoring_profile() tier: str, pack: str='general' List[str] Returns the list of mandatory deliverable codes matching governance tier (1, 2, 3) and methodology pack.
get_lexicon() category: Optional[str]=None List[dict] Returns bilingual PMI PMBOK® and Saudi DGA project management terminology mappings.
validate_artifact_data() artifact_id: str, data: dict, mode='strict' ValidationReport Validates structured payload against Draft 2020-12 companion schema with strict RFC format checking.
render_artifact() artifact_id: str, lang='en', data=None, out_path=None str Compiles deliverable template and data dictionary into styled, print-ready HTML with Arabic RTL support.

Comprehensive Python SDK Example

import tasleemat

# 1. Resolve tailored deliverable bundle for a Tier 2 Agile Project
required_ids = tasleemat.get_tailoring_profile(tier="2", pack="agile")
print(f"Mandatory deliverables count: {len(required_ids)}")

# 2. Extract bilingual prompt instructions for Project Charter (PMO-03.01)
prompt_en = tasleemat.get_artifact_asset("PMO-03.01", role="prompt", lang="en")
prompt_ar = tasleemat.get_artifact_asset("PMO-03.01", role="prompt", lang="ar")

# 3. Inspect companion JSON Schema
schema_def = tasleemat.get_artifact_asset("PMO-03.01", role="schema", lang="en")
print(f"Root schema ID: {schema_def.get('$id')}")

# 4. Programmatic Data Validation (Strict Mode)
charter_payload = {
    "project_code": "PRJ-2026-CLOUD",
    "project_name": "Unified Cloud Transformation",
    "start_date": "2026-11-01",              # Valid RFC 3339 full-date
    "sponsor_name": "Dr. Khalid Al-Mansour",
    "estimated_budget": 3500000.00
}

report = tasleemat.validate_artifact_data("PMO-03.01", charter_payload, mode="strict")
if report.valid:
    print(f"✅ Schema valid! Fingerprint: {report.fingerprint}")
else:
    print(f"❌ Validation failed with {len(report.errors)} error(s):")
    for err in report.errors:
        print(f"   • {err.field_path}: {err.message} (Code: {err.code})")

# 5. Render to styled print-ready HTML
html_output = tasleemat.render_artifact(
    artifact_id="PMO-03.01",
    lang="ar",
    data={"Project_Name": "مشروع التحول السحابي", "Project_Code": "PRJ-2026-CLOUD"},
    out_path="./exports/charter_rendered.html"
)

4. Model Context Protocol (MCP) Integration

Stdio JSON-RPC 2.0

Tasleemat includes an official zero-dependency Model Context Protocol (MCP) server conforming to protocol version 2024-11-05. It exposes 6 specialized tools that allow AI assistants (Claude Desktop, Cursor, OpenCode, Antigravity) to discover deliverables, retrieve prompts and templates, query bilingual terminology, validate structured payloads, and render HTML.

Client Configuration Setup

Add the Tasleemat server block to your client configuration file:

  • Claude Desktop: ~/.config/Claude/claude_desktop_config.json (Linux) or ~/Library/Application Support/Claude/claude_desktop_config.json (macOS)
  • Cursor IDE: .cursor/mcp.json or Settings → Features → MCP
  • OpenCode / Antigravity: Stdio process command tasleemat mcp or tasleemat-mcp
// claude_desktop_config.json or .cursor/mcp.json
{
  "mcpServers": {
    "tasleemat": {
      "command": "tasleemat",
      "args": ["mcp"]
    }
  }
}

The 6 Core MCP Tools

MCP Tool Name Parameters Autonomous Agent Purpose
tasleemat_list_artifacts phase?: string, tier?: string Allows the agent to dynamically inspect required deliverables across the 8 project phases.
tasleemat_get_artifact artifact_id: string Returns canonical deliverable metadata, English/Arabic names, and authoritative SHA-256 fingerprints.
tasleemat_get_asset artifact_id: string, role: string, lang?: "en"|"ar" Retrieves raw text for template, guide, prompt, schema, dictionary, or example.
tasleemat_get_lexicon category?: string, query?: string Prevents semantic translation drift by returning verified PMI PMBOK® and Saudi DGA terminology.
tasleemat_validate_data artifact_id: string, data: object, mode?: "strict"|"draft" Validates structured payload against Draft 2020-12 schema; returns machine-parseable error lists on failure.
tasleemat_render_artifact artifact_id: string, lang?: "en"|"ar", data?: object Renders the validated deliverable to standalone HTML for human gatekeeper review and executive sign-off.

5. Draft 2020-12 Schemas & Strict RFC Format Validation

Every one of the 114 deliverables in Tasleemat is paired with a companion JSON Schema conforming to the JSON Schema Draft 2020-12 specification. Per Draft 2020-12, format annotations are optional by default; however, Tasleemat’s pure-Python validation engine explicitly operates in assertion mode to guarantee semantic data contracts.

Registered RFC Format Handlers

Format Keyword Standard Specification Validation Rules & Edge Cases Handled
date RFC 3339 full-date Strict YYYY-MM-DD. Validates calendar boundaries (rejects Feb 29 on non-leap years, invalid months, unpadded days).
date-time RFC 3339 date-time Requires date, T separator, time, and timezone offset (Z or +/-HH:MM). Supports leap second 60.
time RFC 3339 partial-time HH:MM:SS[.fractional][Z|offset] syntax check.
uuid RFC 4122 UUID Exact 8-4-4-4-12 hex representation (36 chars). Bare UUIDs only; URN schemes belong under uri.
uri RFC 3986 URI Absolute URI requiring scheme (e.g. https://). Disallows raw whitespace or unescaped characters.
uri-reference RFC 3986 URI Reference Allows either absolute URI or valid relative reference without whitespace.
email RFC 5322 addr-spec Standard local-part@domain. Max length 254 octets. Rejects whitespace and invalid domain labels.
duration ISO 8601 / RFC 3339 Duration strings (e.g. P1Y2M, PT15M, P4W). Rejects bare P or PT and prose.

Strict Mode vs. Draft Mode

🔒 Strict Mode (Stage-Gate Enforcement)

Enforces all mandatory keys (required), type safety, numerical bounds, regex patterns, and RFC formats. Returns valid=False on any discrepancy. Used at formal stage-gate approvals and CI/CD quality gates.

📝 Draft Mode (Agent Work-in-Progress)

Permits incomplete payloads and missing required fields while surfacing non-blocking warnings. Allows AI agents to draft preliminary sections incrementally across conversational turns before final packaging.

6. The Autonomous Agent Self-Correction Loop

When LLM agents generate structured deliverables, subtle syntax discrepancies (such as dates formatted as MM/DD/YYYY, boolean fields written as strings "true", or negative budget figures) are common. Tasleemat's deterministic validation engine acts as a surgical compiler error reporter, enabling autonomous self-healing.

flowchart TD RAW["Raw Project Context & Notes"] --> LLM["LLM Agent (Gemini / Claude / GPT)"] LLM --> JSON["Draft JSON Payload"] JSON --> VALIDATE{"tasleemat.validate_artifact_data(strict=True)"} VALIDATE -->|valid == True| RENDER["tasleemat.render_artifact()"] RENDER --> HUMAN["Human Gatekeeper Approval"] VALIDATE -->|valid == False| SURGICAL["Extract Structured Error List:
- field_path: start_date
- code: FORMAT_VIOLATION
- rule: RFC 3339 (YYYY-MM-DD)"] SURGICAL --> REPROMPT["Automated Re-Prompt Feedback Context"] REPROMPT --> LLM

Self-Correction Python Implementation

import tasleemat
from tasleemat.ai import AIClient

def generate_and_heal_deliverable(artifact_id: str, raw_notes: str, max_attempts: int = 3) -> dict:
    client = AIClient(provider="gemini", model="gemini-2.5-flash")
    schema_def = tasleemat.get_artifact_asset(artifact_id, role="schema", lang="en")
    prompt_instructions = tasleemat.get_artifact_asset(artifact_id, role="prompt", lang="en")
    
    system_prompt = (
        f"You are an AI PMO Engineer. Generate a valid JSON object matching the JSON Schema Draft 2020-12.\n"
        f"Schema ID: {schema_def.get('$id')}\n"
        f"Strict RFC formatting is enforced: dates must be YYYY-MM-DD, numbers must be non-negative."
    )
    
    current_prompt = f"{prompt_instructions}\n\nPROJECT NOTES:\n{raw_notes}"
    
    for attempt in range(1, max_attempts + 1):
        raw_response = client.generate(prompt=current_prompt, system_instruction=system_prompt)
        # Parse generated JSON
        payload = extract_json_block(raw_response)
        
        # Execute pure-Python schema verification
        report = tasleemat.validate_artifact_data(artifact_id, payload, mode="strict")
        if report.valid:
            print(f"✅ Deliverable {artifact_id} successfully validated on attempt {attempt}!")
            return payload
            
        print(f"⚠️ Attempt {attempt} failed schema checks. Assembling surgical feedback...")
        error_context = "\n".join([f"- Field '{e.field_path}': {e.message} (Rule: {e.schema_rule})" for e in report.errors])
        
        # In-context surgical re-prompting
        current_prompt = (
            f"Your previous JSON output contained schema validation errors:\n{error_context}\n\n"
            f"Fix ONLY these fields and return the updated valid JSON object without commentary."
        )
        
    raise RuntimeError(f"Deliverable {artifact_id} could not be validated after {max_attempts} attempts.")

Recommended Agent Persona Blueprints

1. PMO Lead Orchestrator (Virtual PMO Director)

Responsibility: Invokes get_tailoring_profile(tier, pack) to establish the governance deliverable baseline. Enforces the Directed Acyclic Graph (DAG) dependencies (e.g., ensuring PMO-03.01 Charter is approved before PMO-04.02.06 WBS is drafted).

Tool Access: tasleemat_list_artifacts, tasleemat_get_artifact, get_tailoring_profile

2. Authoring Agents (Business Analyst, Schedule Engineer, Risk Specialist)

Responsibility: Synthesizes specific deliverable sections using get_artifact_asset(role="prompt") and references the 228 verified real-world examples in examples/en/ and examples/ar/.

Tool Access: tasleemat_get_asset, tasleemat_get_lexicon

3. Gatekeeper QA Agent (Audit & Compliance Lead)

Responsibility: Executes validate_artifact_data(mode="strict") on all completed JSON artifacts. Blocks progression to subsequent lifecycle phases if any required fields or RFC constraints fail.

Tool Access: tasleemat_validate_data, tasleemat_render_artifact

9. CI/CD Pipelines & Headless Quality Gates

Enforce a strict Docs-as-Code philosophy by integrating Tasleemat validation gates into your Git pipelines. Prevent broken schemas, unverified templates, or missing translations from merging into protected branches.

GitHub Actions Workflow Example (.github/workflows/pmo-governance.yml)

name: PMO Governance & Schema Quality Gates

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  validate-governance:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"
          cache: "pip"

      - name: Install Tasleemat & Dependencies
        run: |
          pip install --upgrade pip
          pip install tasleemat

      - name: Validate Completed Artifact JSON Files
        run: |
          # Recursively validate all project deliverable JSON files against companion schemas
          python3 -c "
          import pathlib, sys, json, tasleemat
          errors = 0
          for p in pathlib.Path('workspaces').rglob('*.json'):
              art_id = p.stem.split('.')[0] # e.g. PMO-03.01
              if art_id.startswith('PMO-'):
                  data = json.loads(p.read_text(encoding='utf-8'))
                  report = tasleemat.validate_artifact_data(art_id, data, mode='strict')
                  if not report.valid:
                      print(f'❌ Validation failed for {p}: {report.errors}')
                      errors += 1
          if errors > 0:
              sys.exit(1)
          print('✅ All project deliverables passed strict schema quality gates!')
          "

      - name: Run Test Suite
        run: |
          tasleemat test -v

10. Attested Computations & Deterministic Math Contracts

PMO-06.05 EVA

LLMs are notorious for mathematical hallucination when calculating financial and earned-value progress metrics. Tasleemat establishes strict Attested Computation Contracts where financial metrics are calculated deterministically by dedicated offline tools and verified cryptographically before publication.

Earned Value Analysis Computation Contract (PMO-06.05)

Metric Standard Formula Deterministic Rounding Rule
Schedule Variance (SV) SV = EV - PV Exact decimal currency match (± 0.01 tolerance)
Cost Variance (CV) CV = EV - AC Exact decimal currency match (± 0.01 tolerance)
Schedule Performance Index (SPI) SPI = EV / PV Half-up to 2 decimal places (handles PV=0 as 0.0)
Cost Performance Index (CPI) CPI = EV / AC Half-up to 2 decimal places (handles AC=0 as 0.0)
Estimate at Completion (EAC) EAC = BAC / CPI Half-up to 2 decimal places
To-Complete Performance Index (TCPI) TCPI = (BAC - EV) / (BAC - AC) Half-up to 2 decimal places

When autonomous agents synthesize Earned Value Reports (PMO-06.05), the pipeline invokes tools/attested_computations/eva_calculator.py to produce verifiable ground truth and eva_attester.py to verify that the table presented in the markdown document matches mathematical reality prior to stage-gate approval.
