1. Quick Installation & Environment Prerequisites

PyPI: tasleemat

Tasleemat is distributed as a zero-dependency, pure-Python package on PyPI, supporting Python 3.9, 3.10, 3.11, 3.12, and 3.13. The core distribution packages all 114 bilingual deliverable templates, JSON companion schemas, CSV data dictionaries, CLI commands, and the Model Context Protocol (MCP) server. 

# Install from PyPI
pip install tasleemat

# Verify both CLI and MCP executables
tasleemat --version
tasleemat-mcp --help

2. CLI Command Reference

Dedicated CLI Page →

Scaffold customized workspaces (tasleemat init), search across English and Arabic deliverables (tasleemat search), configure LLM credentials securely (tasleemat config), synthesize draft documents (tasleemat generate), and run internal acceptance test suites (tasleemat test). 

tasleemat init --tier 2 --pack agile --lang ar --code "PRJ-CLOUD" --name "مشروع السحابة" --out ./prj

3. Python SDK Core Architecture

Dedicated SDK Page →

Pure-Python API exporting 8 verified functions: list_artifacts, get_artifact_definition, get_artifact_assets, get_artifact_asset, get_tailoring_profile, validate_artifact_data, get_lexicon, and render_artifact. 

import tasleemat
profile = tasleemat.get_tailoring_profile(tier=2, pack="agile")
report = tasleemat.validate_artifact_data("PMO-03.01", {"project_id": "PRJ-01"}, mode="draft")

4. Model Context Protocol (MCP) Server

Dedicated MCP Page →

Standard JSON-RPC 2.0 stdio server providing 6 specialized tools for Claude Desktop, Cursor, and AI agents: tasleemat_list_forms, tasleemat_get_form, tasleemat_get_schema, tasleemat_validate, tasleemat_tailor_project, and tasleemat_calculate_eva. 

# Run standalone MCP server
tasleemat-mcp

5. JSON Schemas & RFC Formats

Dedicated Schemas Page →

All 114 deliverables feature companion JSON schemas conforming strictly to JSON Schema Draft 2020-12. Enforces strict format validations for RFC 3339 (dates/timestamps), RFC 4122 (UUIDs), RFC 3986 (URIs), and RFC 5322 (emails).

6. The Autonomous Agent Self-Correction Loop

Read Self-Correction Guide →

Autonomous agents don't guess: when LLMs generate invalid JSON or markdown tables, tasleemat.validate_artifact_data returns exact JSON path errors. The agent incorporates the error message into its subsequent prompt to heal the output automatically.
