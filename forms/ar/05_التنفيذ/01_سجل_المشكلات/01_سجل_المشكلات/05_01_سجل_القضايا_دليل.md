# سجل القضايا - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في سجل القضايا.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **المعرف (ID)** | أدخل معرفًا فريدًا للقضية. |
| **النوع** | وثق نوع أو فئة القضية، مثل قضية تتعلق بالمعنيين، قضية فنية، تعارض، إلخ. |
| **مصدر القضية** | السبب الجذري أو المصدر الأصلي للقضية. |
| **وصف القضية** | قدم وصفًا تفصيليًا للقضية. |
| **الأولوية** | حدد الأولوية، مثل عاجلة، عالية، متوسطة، أو منخفضة. |
| **التأثير على الأهداف** | حدد أهداف المشروع التي تؤثر عليها القضية ودرجة التأثير. |
| **المعنيون المتأثرون** | المعنيون الذين يتأثرون أو يجب أن يشاركوا في حل القضية. |
| **الطرف المسؤول** | حدد الشخص المعين لحل القضية. |
| **الحالة** | حدد حالة القضية كمفتوحة أو مغلقة. |
| **تاريخ الحل** | وثق التاريخ الذي يجب حل القضية بحلوله. |
| **الحل النهائي** | صف كيف تم حل القضية. |
| **ملاحظات** | وثق أي تعليقات توضيحية حول القضية، أو الحل، أو أي حقول أخرى في النموذج. |
