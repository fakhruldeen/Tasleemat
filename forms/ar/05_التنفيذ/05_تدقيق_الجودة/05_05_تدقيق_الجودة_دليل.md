# تدقيق الجودة - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في تدقيق الجودة.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **المجال الذي تم تدقيقه** | ضع علامة في المربع للمجال أو المجالات التي تم تدقيقها. |
| **الممارسات الجيدة من مشاريع مماثلة** | صف أي ممارسات جيدة أو أفضل الممارسات التي يمكن مشاركتها من مشاريع مماثلة. |
| **مجالات التحسين** | صف أي مجالات تحتاج إلى تحسين والتحسينات أو القياسات المحددة التي يجب تحقيقها. |
| **أوجه القصور أو العيوب** | حدد العيب أو وجه القصور المعين، والإجراء التصحيحي اللازم، والطرف المسؤول، وتاريخ الاستحقاق. |
| **تتبع تنفيذ التغييرات المعتمدة** | تتبع تنفيذ التغييرات المعتمدة والإجراءات التصحيحية أو الوقائية. |
| **المعلومات المراد مشاركتها مع مشاريع أخرى** | قم بتضمين المعلومات أو الدروس المستفادة التي سيتم مشاركتها مع مشاريع أخرى. |
| **ملاحظات** | قدم أي تعليقات إضافية مفيدة حول التدقيق. |
