# سجل القرارات - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في سجل القرارات.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **المعرف (ID)** | أدخل معرفًا فريدًا للقرار. |
| **الفئة** | وثق نوع القرار، مثل فني، مشروع، عملية، إلخ. |
| **القرار** | قدم وصفًا تفصيليًا للقرار. |
| **التأثيرات على التسليمات/الأهداف** | حدد كيف سيؤثر هذا القرار على تسليمات المشروع أو الأهداف رفيعة المستوى. |
| **المعنيون المتأثرون** | وثق المعنيين المتأثرين أو المشاركين في صنع القرار أو الذين يجب إبلاغهم بالقرار. |
| **الطرف المسؤول** | حدد الشخص المخول باتخاذ القرار. |
| **التاريخ** | أدخل تاريخ اتخاذ القرار واعتماده. |
| **ملاحظات** | أدخل أي معلومات إضافية لتوضيح القرار، والبدائل التي تم النظر فيها، والسبب الذي تم من أجله اتخاذ القرار، وتأثيره. |
