> **السياق والتعريف المهني:**
> سجل شامل يوثق كافة طلبات التغيير المقدمة أثناء دورة حياة المشروع وقرارات مجلس ضبط التغيير بشأنها.

> **المحاذاة وسلسلة الاعتماديات:**
> * **المدخلات (المتطلبات السابقة):**
>   * *إلزامي:* خطة إدارة المشروع (PMO-04.01.01)، خطوط الأساس المعتمدة (النطاق / الجدول / التكلفة)
>   * *اختياري:* سجل المخاطر (PMO-04.08.02)، خطة إشراك المعنيين (PMO-04.10.01)
> * **المخرجات (النماذج التابعة):**
>   * *إلزامي:* تقارير حالة المشروع (PMO-06.01)، سجل التغييرات (PMO-05.04)، ملخص الدروس المستفادة (PMO-07.01)
>   * *اختياري:* تحليل التباين (PMO-06.04)، سجل القرارات (PMO-05.02)

## مدخلات سجل التغييرات

### المعرف
**التعليمات:** معرف فريد لطلب التغيير (مثل CR-01) لضمان التتبع والتوثيق.

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### الفئة
**التعليمات:** فئة التغيير (النطاق، الجدول الزمني، التكلفة، الجودة، الموارد).

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### الوصف
**التعليمات:** وصف موجز وواضح لتفاصيل التغيير المقترح وأهدافه.

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### مقدم الطلب
**التعليمات:** اسم مقدم طلب التغيير أو الإدارة التابع لها.

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### تاريخ التقديم
**التعليمات:** تاريخ تقديم طلب التغيير رسمياً للمراجعة.

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### الحالة
**التعليمات:** الحالة الحالية لطلب التغيير (مقدم، قيد الدراسة، معتمد، مرفوض).

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### القرار
**التعليمات:** قرار مجلس ضبط التغيير (CCB) بشأن اعتماد أو رفض الطلب.

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### تأثير التكلفة أو الجدول الزمني
**التعليمات:** التأثير المالي والزمني المقدر لتنفيذ التغيير المعتمد.

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### النوع (إلزامي أو تقديري)
**التعليمات:** تحديد ما إذا كان التغيير إلزامياً أو تقديرياً.

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### العناصر القابلة للتهيئة المتأثرة
**التعليمات:** العناصر القابلة للتهيئة والخطوط المرجعية المتأثرة بالتغيير.

**القيمة المولَّدة:** [ أضف التفاصيل... ]
