# سجل التغييرات - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في سجل التغييرات.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **المعرف (ID)** | أدخل معرفًا فريدًا للتغيير. |
| **الفئة** | أدخل الفئة من نموذج طلب التغيير. |
| **النوع (إلزامي/تقديري)** | أشر إلى ما إذا كان التغيير إلزاميًا (مثل متطلب قانوني) أو تقديريًا. |
| **إصلاح خطأ برمجي؟ (نعم/لا)** | أشر إلى ما إذا كان التغيير مخصصًا لإصلاح خطأ أو عيب (شائع في مشاريع تكنولوجيا المعلومات). |
| **الوصف** | صف التغيير المقترح. |
| **مقدم الطلب** | أدخل اسم الشخص الذي طلب التغيير. |
| **تاريخ التقديم** | أدخل التاريخ الذي تم فيه تقديم التغيير. |
| **تأثير التكلفة/الجدول الزمني** | ملخص موجز لكيفية تأثير هذا التغيير على ميزانية المشروع أو جدوله الزمني. |
| **العناصر القابلة للتهيئة المتأثرة** | سجل المعلومات لتتبع إدارة التهيئة (ما هي العناصر/المكونات المتأثرة). |
| **الحالة** | أدخل الحالة كمفتوح، معلق، أو مغلق. |
| **القرار** | أدخل نتيجة طلب التغيير كمعتمد، مؤجل، أو مرفوض. |
