# سجل الدروس المستفادة - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في سجل الدروس المستفادة.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **المعرف (ID)** | أدخل معرفًا فريدًا للدرس. |
| **الفئة** | وثق فئة الدرس، مثل العمليات، الفني، البيئي، المعنيين، المرحلة، إلخ. |
| **المحفز** | صف السياق أو الحدث أو الشرط الذي أدى إلى التحدي أو المشكلة أو النتيجة المفيدة. |
| **الدرس** | وضح الدرس الذي يمكن نقله إلى مشاريع أخرى وإلى المؤسسة. |
| **الطرف المسؤول** | حدد الشخص المعين لتنفيذ أي تغييرات لضمان إيصال الدرس ونشره. |
| **مقدم/محدد الدرس** | الشخص الذي حدد الدرس أو قدمه (إذا كان مختلفًا عن الطرف المسؤول). |
| **فرصة وتاريخ التنفيذ التالي** | سجل متى وأين يمكن تطبيق هذا الدرس بشكل فعال لأول مرة لضمان اتخاذ إجراء بشأنه. |
| **تأثير تنظيمي؟ (نعم/لا)** | أشر إلى ما إذا كان الدرس يؤثر على نظام تنظيمي، سياسة، أو ممارسة (نعم) أو يمكن تنفيذه محليًا دون تصعيد (لا). |
| **ملاحظات** | وثق أي تعليقات توضيحية حول التحدي أو المشكلة أو الممارسة الجيدة أو الحقول الأخرى في النموذج. |
