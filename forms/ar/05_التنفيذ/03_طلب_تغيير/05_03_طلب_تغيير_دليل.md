# طلب تغيير - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في طلب التغيير.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **اسم وطالب التغيير ومنصبه** | الاسم، وإذا كان مناسبًا، منصب الشخص الذي يطلب التغيير. |
| **فئة التغيير** | ضع علامة في مربع للإشارة إلى فئة التغيير. |
| **نوع التغيير** | أشر إلى ما إذا كان التغيير إلزاميًا (مثل متطلب قانوني) أو تقديريًا. |
| **وصف التغيير** | صف التغيير المقترح بتفصيل كافٍ لإيصال جميع جوانب التغيير بوضوح. |
| **مبرر التغيير المقترح** | أشر إلى سبب التغيير. |
| **الآثار المترتبة على عدم إجراء التغيير** | صف الآثار أو المخاطر المترتبة على عدم تنفيذ هذا التغيير. |
| **تأثيرات التغيير** | صف تأثير التغيير المقترح على أبعاد محددة للمشروع (النطاق، الجودة، المتطلبات، التكلفة، الجدول الزمني، مستندات المشروع). |
| **ملاحظات** | قدم أي تعليقات توضح المعلومات حول التغيير المطلوب. |
