# تقييم أداء الفريق - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في تقييم أداء الفريق.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **الأداء الفني** | قيم قدرة الفريق على إنجاز النطاق، الجودة، الجدول الزمني، والتكلفة. قدم تعليقات تبريرية. |
| **الكفاءة الشخصية** | قيم قدرة الفريق على التواصل، التعاون، إدارة الصراعات، واتخاذ القرار. |
| **خصائص الفريق** | صف الروح المعنوية العامة للفريق والتماسك. |
| **نقاط قوة وضعف الفريق** | حدد نقاط القوة والضعف الأساسية للفريق. |
| **مجالات التطوير** | اذكر المجالات الفنية أو الشخصية للتطوير، والنهج (تدريب، توجيه)، والإجراءات اللازمة. |
