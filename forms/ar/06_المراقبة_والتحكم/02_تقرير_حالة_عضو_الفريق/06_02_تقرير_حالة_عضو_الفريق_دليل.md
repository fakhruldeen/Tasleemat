# تقرير حالة عضو الفريق - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في تقرير حالة عضو الفريق.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **معلومات التقرير** | قدم تواريخ فترة التقرير، اسم عضو الفريق، دوره، واسم عضو الفريق الذي أعد الوثيقة. |
| **الأنشطة المخطط لها خلال فترة التقرير الحالية** | اذكر جميع الأنشطة المجدولة لهذه الفترة، بما في ذلك العمل الذي سيتم البدء فيه، الاستمرار فيه، أو إكماله. |
| **الأنشطة المنجزة خلال فترة التقرير الحالية** | اذكر جميع الأنشطة التي تم إنجازها هذه الفترة، بما في ذلك العمل الذي تم البدء فيه، الاستمرار فيه، أو إكماله. |
| **الأنشطة المخطط لها ولكن لم يتم إنجازها خلال فترة التقرير الحالية** | اذكر جميع الأنشطة التي تمت جدولتها لهذه الفترة، ولكن لم يتم البدء فيها، الاستمرار فيها، أو إكمالها. |
| **السبب الجذري لتباينات الجدول الزمني** | لأي عمل لم يتم إنجازه كما هو مجدول، حدد سبب التباين. |
| **الأموال المخطط إنفاقها خلال فترة التقرير الحالية** | سجل الأموال التي كان من المخطط إنفاقها هذه الفترة. |
| **الأموال التي تم إنفاقها خلال فترة التقرير الحالية** | سجل الأموال التي تم إنفاقها هذه الفترة. |
| **السبب الجذري لتباينات التكلفة** | لأي نفقات تجاوزت الخطة أو قلت عنها، حدد سبب التباين. قم بتضمين معلومات عن تباينات العمل مقابل المواد. حدد ما إذا كان أساس التقديرات أو الافتراضات غير دقيق. |
| **تباينات الجودة المحددة خلال هذه الفترة** | حدد أي أداء للمنتج أو تباين في الجودة. |
| **الإجراء التصحيحي أو الوقائي المخطط له** | حدد أي إجراءات ضرورية لتدارك تباينات التكلفة أو الجدول الزمني أو الجودة أو منع التباينات المستقبلية. |
| **الأنشطة المخطط لها لفترة التقرير القادمة** | اذكر جميع الأنشطة المجدولة للفترة القادمة، بما في ذلك العمل الذي سيتم البدء فيه، الاستمرار فيه، أو إكماله. |
| **التكاليف المخطط لها لفترة التقرير القادمة** | حدد الأموال المخطط إنفاقها في الفترة القادمة. |
| **المخاطر الجديدة المحددة** | حدد أي مخاطر جديدة نشأت. يجب تسجيل المخاطر الجديدة في سجل المخاطر أيضًا. |
| **المشكلات الجديدة المحددة** | حدد أي مشكلات جديدة نشأت. يجب تسجيل المشكلات الجديدة في سجل المشكلات أيضًا. |
| **قضايا التصعيد** | حدد المجالات التي تحتاج إلى تصعيدها إلى الراعي، مدير البرنامج، أو الفرد المناسب الآخر. |
| **القرارات المتخذة** | سجل القرارات المتخذة. يتم نقل هذه القرارات إلى سجل قرارات المشروع. |
| **الدروس المستفادة / نقل المعرفة** | سجل نقل المعرفة أو الدروس المستفادة. يمكن بعد ذلك نقلها إلى مستودع المعرفة في المؤسسة أو سجل الدروس المستفادة. |
| **ملاحظات** | وثق أي تعليقات تضيف صلة بهذا التقرير. |
