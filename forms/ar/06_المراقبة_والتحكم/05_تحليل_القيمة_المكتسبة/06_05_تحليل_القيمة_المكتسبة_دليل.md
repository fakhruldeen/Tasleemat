# تحليل القيمة المكتسبة - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في تحليل القيمة المكتسبة.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **القيمة المخططة** | أدخل قيمة العمل المخطط إنجازه. |
| **القيمة المكتسبة** | أدخل قيمة العمل الذي تم إنجازه فعليًا. |
| **التكلفة الفعلية** | أدخل تكلفة العمل المنجز. |
| **تباين الجدول الزمني** | احسب تباين الجدول الزمني بطرح القيمة المخططة من القيمة المكتسبة. SV = EV – PV |
| **تباين التكلفة** | احسب تباين التكلفة بطرح التكلفة الفعلية من القيمة المكتسبة. CV = EV – AC |
| **مؤشر أداء الجدول الزمني** | احسب مؤشر أداء الجدول الزمني بقسمة القيمة المكتسبة على القيمة المخططة. SPI = EV/PV |
| **مؤشر أداء التكلفة** | احسب مؤشر أداء التكلفة بقسمة القيمة المكتسبة على التكلفة الفعلية. CPI = EV/AC |
| **السبب الجذري لتباين الجدول الزمني** | حدد السبب الجذري لتباين الجدول الزمني. |
| **تأثير الجدول الزمني** | صف التأثير على التسليمات، المعالم، أو المسار الحرج. |
| **السبب الجذري لتباين التكلفة** | حدد السبب الجذري لتباين التكلفة. |
| **تأثير الميزانية** | صف التأثير على ميزانية المشروع، أموال الطوارئ والاحتياطيات، وأي إجراءات مقصودة لمعالجة التباين. |
| **نسبة المخطط** | أشر إلى النسبة المئوية التراكمية للعمل المخطط إنجازه. PV/BAC |
| **نسبة المكتسب** | أشر إلى النسبة المئوية التراكمية للعمل الذي تم إنجازه. EV/BAC |
| **نسبة المنفق** | أشر إلى إجمالي التكاليف المنفقة لإنجاز العمل. AC/BAC |
| **التقديرات عند الاكتمال** | حدد طريقة مناسبة للتنبؤ بإجمالي النفقات عند اكتمال المشروع. احسب التنبؤ وبرر سبب اختيار التقدير المعين عند الاكتمال. |
| **مؤشر الأداء حتى الاكتمال** | احسب العمل المتبقي مقسومًا على الأموال المتبقية. TCPI = (BAC – EV)/(BAC – AC) أو TCPI = (BAC – EV)/(EAC – AC). |
