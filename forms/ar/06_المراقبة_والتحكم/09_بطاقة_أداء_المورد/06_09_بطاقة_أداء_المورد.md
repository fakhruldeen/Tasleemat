# بطاقة أداء المورد - LLM GENERATION GUIDE

> **System Prompt / Instructions:**
> This document serves as the detailed instruction set for generating the `بطاقة أداء المورد`. Reference `parameters.md` for global project variables.

---

### Metric/KPI
**Instruction:** What is being measured (e.g., Quality, Timeliness).

### Target Score
**Instruction:** Expected performance level.

### Actual Score
**Instruction:** Measured performance.

### Variance
**Instruction:** Difference between target and actual.

### Corrective Action
**Instruction:** Steps to improve if deficient.
