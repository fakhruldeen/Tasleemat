# بطاقة أداء المورد - LLM GENERATION GUIDE

> **موجِّه النظام / التعليمات:**
> يعمل هذا المستند كمجموعة تعليمات تفصيلية لإنشاء السجل. استخدم الإرشادات المقدمة لكل قسم أدناه لإنشاء المحتوى المطلوب بدقة. راجع `parameters.md` لمعرفة متغيرات المشروع العامة.

---

### Metric/KPI
**التعليمات:** What is being measured (e.g., Quality, Timeliness).

---

### Target Score
**التعليمات:** Expected performance level.

---

### Actual Score
**التعليمات:** Measured performance.

---

### Variance
**التعليمات:** Difference between target and actual.

---

### Corrective Action
**التعليمات:** Steps to improve if deficient.
