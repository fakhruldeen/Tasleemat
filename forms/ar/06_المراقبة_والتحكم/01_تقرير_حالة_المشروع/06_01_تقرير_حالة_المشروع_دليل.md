# تقرير حالة المشروع - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في تقرير حالة المشروع.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **معلومات التقرير** | قدم تواريخ فترة التقرير واسم مدير المشروع الذي أعد الوثيقة. |
| **الإنجازات خلال فترة التقرير الحالية** | اذكر جميع حزم العمل أو الإنجازات الأخرى المجدولة للإنجاز في فترة التقرير الحالية. |
| **الإنجازات المخطط لها ولكن لم تكتمل خلال فترة التقرير الحالية** | اذكر جميع حزم العمل أو الإنجازات الأخرى المجدولة للفترة الحالية ولكن لم تكتمل. |
| **السبب الجذري لتباينات الجدول الزمني** | حدد سبب التباين لأي عمل لم يتم إنجازه كما هو مجدول للفترة الحالية. |
| **التأثير على المعالم القادمة أو تاريخ استحقاق المشروع** | حدد أي تأثير على أي معالم قادمة أو جدول المشروع الإجمالي لأي عمل لم يتم إنجازه كما هو مجدول. |
| **الإجراء التصحيحي أو الوقائي المخطط له (الجدول الزمني)** | حدد أي إجراءات لازمة لتعويض تباينات الجدول الزمني أو منع تباينات الجدول الزمني المستقبلية. |
| **الأموال التي تم إنفاقها خلال فترة التقرير الحالية** | سجل الأموال التي تم إنفاقها هذه الفترة. |
| **السبب الجذري لتباينات التكلفة** | حدد سبب التباين لأي إنفاق يتجاوز أو يقل عن الخطة. قم بتضمين معلومات عن تباين العمل مقابل تباين المواد. |
| **التأثير على الميزانية الإجمالية أو أموال الطوارئ** | أشر إلى التأثير على الميزانية الإجمالية للمشروع أو ما إذا كان يجب إنفاق أموال الطوارئ. |
| **الإجراء التصحيحي أو الوقائي المخطط له (التكلفة)** | حدد أي إجراءات ضرورية لتدارك تباينات التكلفة أو منع تباينات التكلفة المستقبلية. |
| **الإنجازات المخطط لها لفترة التقرير القادمة** | اذكر جميع حزم العمل أو الإنجازات المجدولة للإنجاز في الفترة القادمة. |
| **التكاليف المخطط لها لفترة التقرير القادمة** | حدد الأموال المخطط إنفاقها في الفترة القادمة. |
| **المخاطر الجديدة المحددة** | حدد أي مخاطر جديدة تم تحديدها هذه الفترة. يجب تسجيل هذه المخاطر في سجل المخاطر أيضًا. |
| **المشكلات الجديدة المحددة** | حدد أي مشكلات جديدة نشأت هذه الفترة. يجب تسجيل هذه المشكلات في سجل المشكلات أيضًا. |
| **قضايا التصعيد** | حدد أي مجالات تحتاج إلى تصعيدها إلى الراعي أو مدير البرنامج أو الأفراد المناسبين الآخرين. |
| **القرارات المتخذة** | سجل القرارات المتخذة. يتم نقل هذه القرارات إلى سجل قرارات المشروع. |
| **طلبات التغيير المقدمة خلال هذه الفترة** | لخص طلبات التغيير المقدمة خلال فترة التقرير وأحل القارئ إلى سجل التغييرات. |
| **الدروس المستفادة / نقل المعرفة** | سجل نقل المعرفة أو الدروس المستفادة. يمكن بعد ذلك نقلها إلى مستودع المعرفة في المؤسسة أو سجل الدروس المستفادة. |
| **ملاحظات** | سجل أي تعليقات تضيف صلة بالتقرير. |
