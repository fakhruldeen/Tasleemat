# تحليل التباين - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في تحليل التباين.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **الفئة** | تشير إلى مجال التباين (الجدول الزمني، التكلفة، الجودة، النطاق). |
| **النتيجة المخطط لها** | صف العمل المخطط له، أو التكاليف المخططة، أو قياسات الجودة المخططة. |
| **النتيجة الفعلية** | صف العمل الذي تم إنجازه فعليًا، أو التكاليف الفعلية المنفقة، أو قياسات الأداء الفعلية. |
| **التباين** | صف أو احسب التباين. |
| **السبب الجذري** | حدد السبب الجذري للتباين. |
| **الاستجابة المخطط لها** | وثق الإجراء التصحيحي أو الوقائي المخطط له. |
| **تداعيات استمرار التباين** | تنبؤ يعتمد على تحليل الاتجاه أو الاستجابات المحددة فيما يتعلق باستمرار التباين. |
| **مطلوب تصعيد** | أشر إلى ما إذا كانت المعلومات بحاجة إلى تصعيد إلى الراعي أو مدير البرنامج أو الأفراد المناسبين الآخرين. |
| **تفاصيل التصعيد** | قدم تفاصيل حول ما يحتاج إلى تصعيد وإلى من. |
| **ملاحظات** | وثق أي تعليقات تضيف صلة بهذا التقرير. |
