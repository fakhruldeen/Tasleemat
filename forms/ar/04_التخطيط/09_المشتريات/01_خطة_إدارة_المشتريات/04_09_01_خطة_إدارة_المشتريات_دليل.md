# خطة إدارة المشتريات - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في خطة إدارة المشتريات.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **تكامل المشتريات: النطاق** | حدد كيف سيتكامل هيكل تجزئة العمل الخاص بالمقاول مع هيكل تجزئة العمل للمشروع. |
| **تكامل المشتريات: الجدول الزمني** | حدد كيف سيتكامل جدول المقاول مع جدول المشروع، بما في ذلك المعالم والعناصر ذات المهل الطويلة. |
| **تكامل المشتريات: التوثيق** | صف كيف ستتكامل وثائق المقاول مع وثائق المشروع. |
| **تكامل المشتريات: المخاطر** | صف كيف سيتكامل تحديد المخاطر وتحليلها والاستجابة لها مع إدارة المخاطر للمشروع ككل. |
| **تكامل المشتريات: إعداد التقارير** | حدد كيف ستتكامل تقارير حالة المقاول مع تقرير حالة المشروع. |
| **توقيت أنشطة المشتريات** | حدد الجدول الزمني لأنشطة الشراء الرئيسية. |
| **مقاييس الأداء** | وثق المقاييس التي سيتم استخدامها لتقييم أداء البائع. |
| **الأدوار والمسؤوليات والصلاحيات** | حدد الأدوار والمسؤوليات ومستوى الصلاحية لمدير المشروع والمقاول وإدارة المشتريات، بالإضافة إلى أي أصحاب مصلحة مهمين آخرين للعقد. |
| **الافتراضات والقيود** | سجل الافتراضات والقيود المتعلقة بأنشطة الشراء. |
| **الولاية القضائية القانونية والعملة** | حدد الموقع الذي له ولاية قضائية قانونية. حدد العملة التي سيتم استخدامها للتسعير والدفع. |
| **التقديرات المستقلة** | وثق ما إذا كان سيتم استخدام تقديرات تكلفة مستقلة وما إذا كانت ستكون مطلوبة لاختيار المصدر. |
| **متطلبات إدارة المخاطر** | وثق متطلبات سندات الأداء أو عقود التأمين للحد من المخاطر. |
| **البائعون المؤهلون مسبقًا** | ضع قائمة بأي بائعين مؤهلين مسبقًا سيتم استخدامهم. |
