# استراتيجية المشتريات - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في استراتيجية المشتريات.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **طرق التسليم** | صف طريقة التسليم (مثل: مشروع مشترك، ممثل، تصميم وبناء، إلخ). |
| **اختيار نوع العقد** | حدد أنواع العقود. |
| **رسوم الحوافز أو المكافآت** | اذكر أي رسوم حوافز أو مكافآت والمعايير المرتبطة بها. |
| **دورة حياة المشتريات** | ضع قائمة بمراحل المشتريات، ومعايير الدخول/الخروج، والتسليمات، ونقل المعرفة. |
