# وثيقة المشروع: سجل المخاطر

**مرجع الوثيقة:** `PMO-04.08.02`

---

### السياق والتعريف
يُسجل سجل المخاطر تفاصيل المخاطر الفردية المحددة. ويوثق نتائج تحليل المخاطر، وتخطيط الاستجابة للمخاطر، وتنفيذ الاستجابة، والحالة الحالية. يُستخدم لتتبع المعلومات حول المخاطر المحددة على مدار المشروع. تتضمن المعلومات النموذجية ما يلي:
*   معرف الخطر
*   بيان الخطر
*   مالك الخطر
*   احتمالية الحدوث
*   الأثر على الأهداف في حال حدوث الخطر
*   درجة الخطر
*   استراتيجيات الاستجابة
*   الاحتمالية المعدلة
*   الأثر المعدل
*   الدرجة المعدلة
*   الإجراءات
*   الحالة
*   التعليقات

يمكن لسجل المخاطر تلقي المعلومات من أي مكان في بيئة المشروع. تشمل بعض المستندات التي يجب مراجعتها بشكل خاص كمدخلات:
*   سجل الافتراضات
*   سجل المشكلات
*   سجل الدروس المستفادة
*   خطة إدارة المتطلبات
*   وثائق المتطلبات
*   الخط المرجعي للنطاق
*   خطة إدارة الجدول الزمني
*   تقديرات المدة
*   الخط المرجعي للجدول الزمني
*   خطة إدارة التكلفة
*   تقديرات التكلفة
*   الخط المرجعي للتكلفة
*   خطة إدارة الجودة
*   خطة إدارة الموارد
*   متطلبات الموارد
*   خطة إدارة المخاطر
*   وثائق المشتريات
*   الاتفاقيات
*   سجل المعنيين

يوفر سجل المخاطر المعلومات إلى:
*   بيان النطاق
*   تقديرات المدة
*   تقديرات التكلفة
*   خطة إدارة الجودة
*   متطلبات الموارد
*   تقرير المخاطر
*   خطة إدارة المشتريات
*   خطة إشراك المعنيين
*   سجل الدروس المستفادة
*   إغلاق المشروع

سجل المخاطر هو مُخرج من العملية 11.2 تحديد المخاطر في الدليل المعرفي لإدارة المشروعات (PMBOK® Guide) - الإصدار السادس. يتم تطويره في بداية المشروع ويتم تحديثه طوال فترة المشروع.

### وصف عناصر الوثيقة

| عنصر الوثيقة | الوصف |
| ---: | ---: |
| **معرف الخطر** | أدخل معرفاً فريداً للخطر. |
| **بيان الخطر** | صف حدث أو حالة الخطر. يُصاغ بيان الخطر عادةً على النحو التالي "قد يحدث [حدث]، مما يتسبب في [أثر]" أو "إذا كانت [حالة] موجودة، فقد يحدث [حدث]، مما يؤدي إلى [تأثير]". |
| **مالك الخطر** | الشخص المسؤول عن إدارة الخطر وتتبعه. |
| **الاحتمالية** | حدد احتمالية حدوث الحدث أو الحالة. |
| **الأثر** | صف الأثر على واحد أو أكثر من أهداف المشروع. |
| **الدرجة** | إذا كنت تستخدم التسجيل الرقمي، فاضرب الاحتمالية في الأثر لتحديد درجة الخطر. |
| **الاستجابة** | صف استراتيجية الاستجابة المخطط لها للخطر أو الحالة. |
| **الاحتمالية المعدلة** | حدد احتمالية حدوث الحدث أو الحالة بعد تنفيذ الاستجابة. |
| **الأثر المعدل** | صف الأثر بمجرد تنفيذ الاستجابة. |
| **الدرجة المعدلة** | أدخل درجة الخطر المعدلة بمجرد تنفيذ الاستجابة. |
| **الإجراءات** | صف أي إجراءات يجب اتخاذها للاستجابة للخطر. |
| **الحالة** | أدخل الحالة كـ "مفتوح" أو "مغلق". |
| **التعليقات** | قدم أي تعليقات أو معلومات مفيدة إضافية حول حدث أو حالة الخطر. |
