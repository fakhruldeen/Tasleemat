# تقرير المخاطر - الدليل الإرشادي
يوفر هذا المستند أوصافًا لكل عنصر في تقرير المخاطر.

| عنصر الوثيقة | الوصف |
| :--- | :--- |
| **تاريخ الإعداد** | التاريخ الذي تم فيه كتابة التقرير. |
| **فترة التقرير** | الإطار الزمني المحدد (مثل: شهر، ربع سنة، مرحلة) الذي يغطيه هذا التقرير. |
| **مدير المشروع** | الشخص المسؤول عن المشروع. |
| **الملخص التنفيذي** | بيان يصف التعرض العام لمخاطر المشروع والمخاطر الفردية الرئيسية، جنباً إلى جنب مع الاستجابات المقترحة للاتجاهات. |
| **حالة المخاطر الكلية والاتجاهات** | بيان عالي المستوى للاتجاهات وحالة المخاطر الحالية. |
| **المحركات الهامة للمخاطر الكلية** | تحديد المحركات الهامة لمخاطر المشروع الكلية. |
| **الاستجابات الموصى بها للمخاطر الكلية** | تحديد الاستجابات الموصى بها للمخاطر الكلية للمشروع. |
| **مصفوفة الاحتمالية والأثر** | تشير إلى عدد المخاطر الفردية الموجودة في كل مربع من مصفوفة 5x5. |
| **المقاييس** | أعداد محددة للمخاطر حسب الهدف (النطاق، الجدول، التكلفة، الجودة)، والاحتمالية (مرتفع جداً، مرتفع، متوسط)، والحالة (نشط، مغلق حديثاً). |
| **المخاطر الحرجة والاستجابات** | جدول يتتبع أهم المخاطر التي تواجه المشروع واستجاباتها المخططة المقابلة. |
| **التغييرات على المخاطر الحرجة** | وصف لأي تعديلات أو تصعيدات أو تغييرات على المخاطر الحرجة منذ التقرير الأخير. |
| **المخاطر المتحققة (المنقولة إلى سجل المشكلات)** | المخاطر التي تحققت وأصبحت مشكلات فعلية خلال فترة التقرير. |
| **النتائج من التقييمات الكمية** | ملخصات المخرجات من النماذج مثل منحنيات S، الرسوم البيانية تورنادو، أو محاكاة مونت كارلو. |
| **احتمالية تلبية الأهداف** | الاحتمالية المحسوبة لتحقيق أهداف النطاق، الجدول الزمني، التكلفة، والجودة. |
| **نطاق النتائج** | نطاق التباين المتوقع لنتائج الجدول الزمني والتكلفة، محركاتها الرئيسية، والاستجابات المقترحة. |
| **إجمالي احتياطي التكلفة** | إجمالي الميزانية المخصصة لاستجابات المخاطر (احتياطي الإدارة واحتياطي الطوارئ). |
| **احتياطي التكلفة المستخدم حتى تاريخه** | المبلغ التراكمي من احتياطي التكلفة المستهلك حتى الآن. |
| **احتياطي التكلفة المستخدم في هذه الفترة** | مبلغ احتياطي التكلفة المستهلك خلال فترة التقرير المحددة هذه. |
| **احتياطي التكلفة المتبقي** | رصيد احتياطي التكلفة المتاح. |
| **إجمالي احتياطي الجدول الزمني** | إجمالي وقت التخزين المؤقت المخصص لاستجابات المخاطر. |
| **احتياطي الجدول الزمني المستخدم حتى تاريخه** | المقدار التراكمي لاحتياطي الجدول الزمني المستهلك حتى الآن. |
| **احتياطي الجدول الزمني المستخدم في هذه الفترة** | مقدار احتياطي الجدول الزمني المستهلك خلال فترة التقرير المحددة هذه. |
| **احتياطي الجدول الزمني المتبقي** | رصيد احتياطي الجدول الزمني المتاح. |
| **تقييم كفاية الاحتياطي** | تقييم ما إذا كانت احتياطيات التكلفة والجدول الزمني المتبقية كافية بالنظر إلى مشهد المخاطر الحالي. |
| **ملخص أحداث المخاطر** | نظرة عامة على أحداث المخاطر التي وقعت وآثارها. |
| **ملخص عمليات إدارة المخاطر** | تقييم مدى فعالية تنفيذ عمليات إدارة المخاطر. |
| **ملخص التوصيات** | توصيات قابلة للتنفيذ ناجمة عن تدقيق المخاطر. |
