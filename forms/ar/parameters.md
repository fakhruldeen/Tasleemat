# المتغيرات العامة للمشروع (Project Parameters)

يحتوي هذا الملف على جميع المتغيرات العامة والعناصر النائبة (Placeholders) المطلوبة عبر نماذج المشروع. عند استخدام نموذج ذكاء اصطناعي (LLM) لإنشاء أو تعبئة النماذج، قم بتزويده بهذه المتغيرات ليتمكن من ملء القوالب بدقة.

## 1. معلومات المشروع
- **اسم المشروع:** `[أدخل اسم المشروع]` (يُستبدل بـ `{{اسم_المشروع}}`)
- **معرف المشروع / الرمز:** `[أدخل معرف المشروع]`
- **وصف المشروع:** `[أدخل وصفاً موجزاً]`
- **تاريخ البدء:** `[أدخل تاريخ البدء]`
- **تاريخ الانتهاء / التاريخ المستهدف:** `[أدخل تاريخ الانتهاء]`
- **التاريخ الحالي:** `[التاريخ الحالي]` (يُستبدل بـ `{{التاريخ_الحالي}}`)
- **وقت الإنشاء:** `[وقت الإنشاء]` (يُستبدل بـ `{{وقت_الإنشاء}}`)

## 2. الأفراد الرئيسيون
- **اسم مدير المشروع:** `[أدخل الاسم]` (يُستبدل بـ `{{اسم_مدير_المشروع}}`)
- **البريد الإلكتروني لمدير المشروع:** `[أدخل البريد الإلكتروني]`
- **اسم راعي المشروع:** `[أدخل الاسم]`
- **البريد الإلكتروني لراعي المشروع:** `[أدخل البريد الإلكتروني]`
- **معد الوثيقة:** `[أدخل اسم المعد]` (يُستبدل بـ `{{معد_الوثيقة}}`)
- **اسم العميل:** `[أدخل اسم العميل]`
- **مؤسسة العميل:** `[أدخل اسم المؤسسة]`

## 3. السياق المؤسسي
- **اسم الشركة / المؤسسة:** `[أدخل اسم الشركة]`
- **القسم / الوحدة المنفذة:** `[أدخل اسم القسم]`
- **اسم البرنامج / المحفظة:** `[أدخل اسم البرنامج، إن وُجد]`

## 4. الشؤون المالية والقيود
- **الميزانية المعتمدة:** `[أدخل الميزانية]`
- **العملة الأساسية:** `[أدخل العملة، مثل: الريال السعودي أو الدولار]`
- **القيود الرئيسية:** `[أدخل القيود الأساسية]`

*ملاحظة للنموذج الذكي (LLM):* استخدم هذه المتغيرات العامة لملء العناصر النائبة المطابقة تلقائياً في قوالب إدارة المشروع المختلفة.
