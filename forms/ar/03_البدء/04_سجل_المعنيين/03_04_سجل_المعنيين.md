> **السياق والتعريف:**
> وثيقة مشروع تتضمن تحديد وتقييم وتصنيف المعنيين بالمشروع ومستويات مشاركتهم.

> **المحاذاة والاعتماديات:**
> * **المتطلبات السابقة (المدخلات):**
>   * *إلزامي:* ميثاق المشروع (PMO-03.01)، الاتفاقيات والعقود المبدئية
>   * *اختياري:* ميثاق البرنامج (PMO-00.02)، الهياكل التنظيمية للمؤسسة
> * **النماذج التابعة (المخرجات):**
>   * *إلزامي:* تحليل المعنيين (PMO-03.05)، خطة إشراك المعنيين (PMO-04.10.01)، خطة إدارة الاتصالات (PMO-04.07.01)
>   * *اختياري:* استراتيجية إدارة التغيير (PMO-04.11.01)، ميثاق الفريق (PMO-04.06.05)

## مدخلات سجل المعنيين

### المعرف
**التعليمات:** معرف فريد للمعني (مثل SH-01) لضمان التتبع والرجوع إليه.

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### الاسم
**التعليمات:** اسم المعني، ويمكن استخدام المنصب أو المؤسسة إذا لم يتوفر الاسم.

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### المنصب / الدور
**التعليمات:** المنصب الوظيفي أو الدور الذي يؤديه المعني في المنظمة أو في فريق المشروع.

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### معلومات التواصل
**التعليمات:** طريقة التواصل مع المعني مثل رقم الهاتف أو البريد الإلكتروني أو العنوان.

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### المتطلبات
**التعليمات:** الاحتياجات والمتطلبات عالية المستوى الخاصة بالمشروع والمنتج.

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### التوقعات
**التعليمات:** التوقعات الرئيسية لنتائج المشروع والتواصل ومستوى المشاركة.

**القيمة المولَّدة:** [ أضف التفاصيل... ]

### التصنيف
**التعليمات:** تصنيف المعنيين (مثل داخلي أو خارجي، أو مستوى التأثير عالي أو متوسط أو منخفض).

**القيمة المولَّدة:** [ أضف التفاصيل... ]
