# VARIANCE ANALYSIS - GUIDANCE
This document provides descriptions for each element in the Variance Analysis.

| Document Element | Description |
| :--- | :--- |
| **Category** | Indicates the area of variance (Schedule, Cost, Quality, Scope). |
| **Planned Result** | Describe the work planned, planned costs, or planned quality measurements. |
| **Actual Result** | Describe the work actually accomplished, actual costs expended, or actual performance measurements. |
| **Variance** | Describe or calculate the variance. |
| **Root Cause** | Identify the root cause of the variance. |
| **Planned Response** | Document the planned corrective or preventive action. |
| **Implications of continued variance** | A forecast based on a trend analysis or identified responses regarding continued variance. |
| **Escalation Required** | Indicate if the information needs to be escalated to the sponsor, program manager, or other appropriate individuals. |
| **Escalation Details** | Provide specifics about what needs escalation and to whom. |
| **Comments** | Document any comments that add relevance to this report. |
