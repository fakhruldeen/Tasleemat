# WBS DICTIONARY - LLM GENERATION GUIDE

> **System Prompt / Instructions:**
> This document serves as the detailed instruction set for generating the `WBS Dictionary`. When asked to populate this form, use the guidance provided for each section below to accurately generate the required content. Reference `parameters.md` for global project variables.

---

### Work package name
**Instruction:** Enter a brief description of the work package deliverable from the WBS.

### Code of account
**Instruction:** Enter the code of account from the WBS.

### Milestones
**Instruction:** List any milestones associated with the work package.

### Due dates
**Instruction:** List the due dates for milestones associated with the work package.

### ID
**Instruction:** Enter a unique activity identifier—usually an extension of the WBS code of accounts.

### Activity
**Instruction:** Describe the activity from the activity list or the schedule.

### Team resource
**Instruction:** Identify the resources, usually from the resource requirements.

### Labor hours
**Instruction:** Enter the total effort required.

### Labor rate
**Instruction:** Enter the labor rate, usually from cost estimates.

### Labor total
**Instruction:** Multiply the effort hours times the labor rate.

### Material units
**Instruction:** Enter the amount of material required, usually from the resource requirements.

### Material cost
**Instruction:** Enter the material cost, usually from cost estimates.

### Material total
**Instruction:** Multiply the material units times the material cost.

### Total cost
**Instruction:** Sum the labor, materials, and any other costs associated with the work package.

### Quality requirements
**Instruction:** Document any quality requirements or metrics associated with the work package.

### Acceptance criteria
**Instruction:** Describe the acceptance criteria for the deliverable, usually from the scope statement.

### Technical information
**Instruction:** Describe or reference any technical requirements or documentation needed to complete the work package.

### Agreement information
**Instruction:** Reference any contracts or other agreements that impact the work package.
