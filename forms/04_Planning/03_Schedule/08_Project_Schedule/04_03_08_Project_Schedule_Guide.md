## Tasleemat Forms Guide
# Project Artifact: Project Schedule

**Document Reference:** `PMO-04.03.08`

This document provides a comprehensive, professional reference to understand
the purpose and effective usage of the **Project Schedule** in alignment with the
Tasleemat framework.

---

### 1. What?
The definitive schedule model documenting start/finish dates, critical path, float, and assigned resources for all work.

---

### 2. Why?
Serves as the authorized baseline to direct daily work, measure progress, and manage project completion commitments.

---

### 3. When?
Baselined upon planning completion and updated at each reporting cycle.

---

### 4. Who?
Maintained by Project Scheduler and Project Manager, approved by Project Sponsor and PMO Director.

---

### Tailoring Tips
*   Represent as sprint and release cadence burndown schedules for agile delivery.
*   Maintain fully detailed Gantt and CPM schedules for complex multi-party contractual engagements.

---

### Alignment
The core Schedule Baseline integrating Activity List, Network Diagram, Duration Estimates, and Earned Value Management.

---

### 5. How?
To accurately and professionally complete the **Project Schedule**, the responsible party
must populate the following critical sections based on the project context (ensure `parameters.md` is referenced for global project variables):

*   **Project Start and Target Finish Dates:** The authorized baseline start date and targeted project completion date.
*   **Schedule Data Version and Baseline Status:** The formal schedule model version number and baseline authorization state.
*   **Total Critical Path Length and Major Phases:** Total working days on the critical path and scheduled durations for each major project phase.
*   **WBS Code and Activity Schedule Mapping:** Consolidated schedule line items linking WBS code, activity title, and work package.
*   **Planned Start and Finish Dates:** Approved baseline start date and baseline completion date for each scheduled activity.
*   **Assigned Resources and Effort Allocation:** Designated resource leads, team members, and allocated effort hours per activity.
*   **Critical Path Flag and Dependencies:** Clear indicator (Yes/No) identifying critical path activities and predecessor linkages.
*   **Total Float and Free Float Values:** Calculated total float and free float values in working days for each schedule activity.
*   **Schedule Risk and Recovery Considerations:** Identification of high-risk scheduling bottlenecks and contingency deployment rules.
