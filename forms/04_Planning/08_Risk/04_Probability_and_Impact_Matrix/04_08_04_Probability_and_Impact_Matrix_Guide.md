# PROBABILITY AND IMPACT MATRIX - GUIDANCE
This document provides descriptions for each element in the Probability and Impact Matrix.

| Document Element | Description |
| :--- | :--- |
| **Probability and Impact Matrix** | The 5x5 grid displaying the calculated numerical risk score for every combination of probability and impact. |
| **Risk Score Thresholds** | The defined bounds (e.g., 0.18 to 0.72) and required actions for High, Medium, and Low severity risks. |
