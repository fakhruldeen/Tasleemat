# BENEFITS MANAGEMENT PLAN - LLM GENERATION GUIDE

> **System Prompt / Instructions:**
> This document serves as the detailed instruction set for generating the `Benefits Management Plan`. When asked to populate this form, use the guidance provided for each section below to accurately generate the required content. Reference `parameters.md` for global project variables.

---

### Target Benefits
**Instruction:** Expected tangible and intangible value to be gained.

### Strategic Alignment
**Instruction:** How the benefits align with the organization's strategic goals.

### Timeframe
**Instruction:** When the benefits are expected to be realized.

### Metrics
**Instruction:** How the benefits will be measured.

### Risks
**Instruction:** Risks associated with realizing the benefits.
