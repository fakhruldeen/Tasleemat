# ASSUMPTION LOG - LLM GENERATION GUIDE

> **System Prompt / Instructions:**
> This document serves as the detailed instruction set for generating the `Assumption Log`. When asked to populate this form, use the guidance provided for each section below to accurately generate the required content. Reference `parameters.md` for global project variables.

---

### ID
**Instruction:** Unique identifier for the assumption or constraint.

---

### Category
**Instruction:** The category of the assumption or constraint (e.g., Technical, Financial, Schedule).

---

### Assumption/constraint
**Instruction:** A clear, detailed description of the assumption or constraint.

---

### Responsible party
**Instruction:** The person who is tasked with following up on the assumption to validate if it is true or not.

---

### Due date
**Instruction:** The date by which the assumption needs to be validated.

---

### Actions
**Instruction:** Specific actions that need to be taken to validate the assumption.

---

### Status
**Instruction:** The current status of the assumption (e.g., active, transferred, or closed).

---

### Comments
**Instruction:** Any additional information, context, or updates regarding the assumption or constraint.
