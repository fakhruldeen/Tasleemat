# TEAM PERFORMANCE ASSESSMENT - GUIDANCE
This document provides descriptions for each element in the Team Performance Assessment.

| Document Element | Description |
| :--- | :--- |
| **Technical Performance** | Rate the team's ability to deliver the scope, quality, schedule, and cost. Provide justifying comments. |
| **Interpersonal Competency** | Rate the team's ability in communication, collaboration, conflict management, and decision making. |
| **Team Characteristics** | Rate and describe the overall team morale and cohesiveness. |
| **Team Strengths and Weaknesses** | Identify, rate, and describe the primary strengths and weaknesses of the team. |
| **Areas for Development** | List technical or interpersonal areas for development, the approach (e.g., training, mentoring, coaching), and necessary actions. |
