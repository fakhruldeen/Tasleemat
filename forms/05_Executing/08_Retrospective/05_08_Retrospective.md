# RETROSPECTIVE - LLM GENERATION GUIDE

> **System Prompt / Instructions:**
> This document serves as the detailed instruction set for generating the log. When asked to populate this form, use the guidance provided for each section below to accurately generate the required content. Reference `parameters.md` for global project variables.

---

### Start
**Instruction:** Actions and behaviors that the team will begin to implement

---

### Stop
**Instruction:** Actions or behaviors that the team will cease doing

---

### Keep
**Instruction:** Practices that the team should continue with

---

### More
**Instruction:** Practices that were not done consistently that should be done more often

---

### Less
**Instruction:** Practices that were done too much or that should be reduced
