# QUALITY AUDIT - GUIDANCE
This document provides descriptions for each element in the Quality Audit.

| Document Element | Description |
| :--- | :--- |
| **Area Audited** | Check the box for the area or areas audited. |
| **Good Practices from Similar Projects** | Describe any good or best practices that can be shared from similar projects. |
| **Areas for Improvement** | Describe any areas that need improvement and the specific improvements or measurements that need to be achieved. |
| **Deficiencies or Defects** | Identify the specific deficiency/defect, the corrective action needed, the responsible party, and the due date. |
| **Implementation Tracking of Approved Changes** | Track the implementation of approved changes and corrective or preventive actions. |
| **Information to Share with Other Projects** | Include information or lessons learned that will be shared with other projects. |
| **Comments** | Provide any additional useful comments about the audit. |
