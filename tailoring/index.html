Governance Sizing Tiers & Delivery Packs

Not every project needs all 114 deliverables. Tasleemat provides structured tailoring profiles that balance governance rigor with operational speed according to project investment scale, risk, and delivery archetype.

⚡ Programmatic Tailoring & Scaffolding

Generate pre-populated project folders with tailored deliverables in one command or query them directly in Python:

CLI Scaffolding Command
# Scaffold Tier 2 Agile Project
tasleemat init \
  --tier 2 \
  --pack agile \
  --lang en \
  --name "Customer Portal v2" \
  --code "PRJ-2026-PORTAL" \
  --out ./portal_project
Python SDK Function
import tasleemat

# Query tailored deliverable IDs
deliverables = tasleemat.get_tailoring_profile(
    tier=2,
    pack="agile"
)
print(f"Tailored count: {len(deliverables)}")
