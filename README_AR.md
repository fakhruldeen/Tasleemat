## 🌟 لمحة عامة عن المشروع

**تسليمات (Tasleemat)** هي حزمة أدوات مؤسسية مفتوحة المصدر لمكاتب إدارة المشاريع (PMO)، موجهة لمدراء المشاريع، مدراء المحافظ والبرامج، مهندسي النظم، ومطوري حلول الذكاء الاصطناعي. توفر الحزمة **94 نموذجاً ووثيقة مشروع ثنائية اللغة (عربي / إنجليزي)** تغطي دورة الحياة الكاملة للمشاريع—بدءاً من إدارة المحافظ وتحقيق القيمة، ومروراً بالتخطيط التنبؤي، وممارسات أجايل (Agile)، وحوكمة الذكاء الاصطناعي.

صُمم كل مخرج ومستند في الحزمة على شكل **حزمة متكاملة من 5 ملفات متزامنة** تجمع بين التطبيق العملي البشري، والتقارير التنفيذية القابلة للطباعة وتصدير PDF، والأتمتة التوليدية بواسطة الذكاء الاصطناعي.

---

## 💎 أبرز مميزات الحزمة

- **📚 94 مخرجاً تغطي دورة الحياة كاملة:** تغطية شاملة لإدارة المحافظ، أجايل، المشاريع التقليدية، وحوكمة الذكاء الاصطناعي.
- **🌐 تطابق ثنائي اللغة بنسبة 100%:** تطابق هيكلي دقيق ومباشر بين النسخ الإنجليزية والنسخ العربية المصممة باتجاه اليمين إلى اليسار (RTL) وفق **معجم مصطلحات معهد إدارة المشاريع (PMI Lexicon)**.
- **🤖 جاهزية كاملة للذكاء الاصطناعي (AI-Native):** يحتوي كل نموذج على مخطط بيانات رقمي `JSON` وموجه تعليمات `Prompt` جاهز للحقن المباشر في نماذج مثل ChatGPT و Claude و Gemini.
- **🖨️ جاهز للطباعة والتصدير كـ PDF:** جداول منسقة بدقة وفق معايير GitHub Markdown و HTML مدعومة بمربعات توقيع حوكمية للأدوار المعتمدة.
- **🔗 اعتماديات متبادلة واضحة:** تحديد دقيق للمدخلات الإلزامية السابقة والمخرجات اللاحقة عبر كافة الأدلة والموجهات.
- **📖 معجم رسمي معتمد للمصطلحات:** توثيق شامل لكافة المصطلحات الإنجليزية وترجماتها الرسمية في [`LEXICON.md`](LEXICON.md) و [`LEXICON.json`](LEXICON.json).

## 📦 حزمة الـ 5 ملفات لكل نموذج

داخل كل مجلد من مجلدات النماذج الـ 94 (مثال: [`forms/ar/03_البدء/01_ميثاق_المشروع/`](forms/ar/03_البدء/01_ميثاق_المشروع/))، ستجد 5 ملفات متكاملة:

| نوع الملف | اللاحقة | القيمة العملية للممارس |
| :--- | :--- | :--- |
| **القالب القابل للطباعة** | `*_قالب.md` | مستند جاهز للطباعة يحتوي على ترويسة الوثيقة الرسمية، الأقسام المنظمة، وجدول توقيعات الاعتماد. |
| **الدليل الإرشادي** | `*_دليل.md` | دليل عملي يشرح الغرض الحوكمي، قواعد الصياغة، إرشادات الأعمدة، والاعتماديات السابقة واللاحقة. |
| **موجه الذكاء الاصطناعي** | `*.md` | موجه تعليمات (Prompt) مصمم لتوجيه نماذج الذكاء الاصطناعي بدقة حول كيفية ملء كل حقل. |
| **مخطط البيانات الرقمي** | `*.json` | مخطط بيانات مقروء آلياً يربط الأقسام، الحقول، الإرشادات، والقيم الافتراضية لمنظومات الـ API. |
| **قاموس الحقول الجدولي** | `*.csv` | جدول من 4 أعمدة (`Section,Field,Guidance,LLM_Generated_Value`) للتحليل عبر Excel و PowerBI. |

## 🗺️ المراحل الزمنية للمشروع (94 نموذجاً)

```mermaid
flowchart LR
    P0["00. المحافظ والبرامج<br/>(4 نماذج)"] --> P1["01. تسليم القيمة<br/>(3 نماذج)"]
    P1 --> P2["02. المنهجية والتخصيص<br/>(6 نماذج)"]
    P2 --> P3["03. البدء<br/>(5 نماذج)"]
    P3 --> P4["04. التخطيط<br/>(32 نموذجاً)"]
    P4 --> P5["05. التنفيذ<br/>(12 نموذجاً)"]
    P5 --> P6["06. المراقبة والتحكم<br/>(10 نماذج)"]
    P6 --> P7["07. الإغلاق<br/>(4 نماذج)"]
```

### 📑 ملخص مجموعات العمليات

1. **[00. إدارة البرامج والمحافظ](forms/ar/00_إدارة_البرامج_والمحافظ/)** (`PMO-00.01` إلى `PMO-00.04`): المواءمة الاستراتيجية، سجل الاعتماديات المتبادلة، ومصفوفة سعة الموارد.
2. **[01. الأعمال وتسليم القيمة](forms/ar/01_الأعمال_وتسليم_القيمة/)** (`PMO-01.01` إلى `PMO-01.03`): دراسات الجدوى وحالات الأعمال، خطة إدارة الفوائد، وسجل تحقيق القيمة.
3. **[02. منهجية المشروع وتخصيصه](forms/ar/02_منهجية_المشروع_وتخصيصه/)** (`PMO-02.01` إلى `PMO-02.06`): خطة التخصيص، حوكمة الذكاء الاصطناعي، بطاقات النماذج، وتقييم الأخلاقيات.
4. **[03. البدء](forms/ar/03_البدء/)** (`PMO-03.01` إلى `PMO-03.05`): ميثاق المشروع، بيان رؤية المنتج، سجل الافتراضات، وسجل وتحليل المعنيين.
5. **[04. التخطيط](forms/ar/04_التخطيط/)** (`PMO-04.01.01` إلى `PMO-04.11.02`): 32 خطة تشمل التكامل، النطاق (هيكل تجزئة العمل WBS)، الجدول الزمني، التكلفة، الجودة، الموارد، الاتصالات، المخاطر، المشتريات، المعنيين، وإدارة التغيير المؤسسي.
6. **[05. التنفيذ](forms/ar/05_التنفيذ/)** (`PMO-05.01` إلى `PMO-05.12`): سجل المشكلات، طلبات وسجلات التغيير، تقييم أداء الفريق، مراجعات المرحلة (Retrospective)، ومكتبة الأوامر.
7. **[06. المراقبة والتحكم](forms/ar/06_المراقبة_والتحكم/)** (`PMO-06.01` إلى `PMO-06.10`): تقارير حالة المشروع، تحليل التباين، تحليل القيمة المكتسبة (EVA)، ونماذج اعتماد اختبار قبول المستخدم (UAT).
8. **[07. الإغلاق](forms/ar/07_الإغلاق/)** (`PMO-07.01` إلى `PMO-07.04`): تقرير إغلاق العقد، ملخص الدروس المستفادة، وإغلاق المشروع أو المرحلة.

*للاطلاع على الفهرس الكامل للنماذج والروابط المباشرة، راجع **[`LEXICON.md`](LEXICON.md)**.*

## ⚡ البدء السريع: 3 طرق للاستفادة من تسليمات

### 1. الاستخدام اليدوي المباشر
1. توجه إلى مجلد المرحلة المطلوبة (مثال: [`forms/ar/03_البدء/01_ميثاق_المشروع/`](forms/ar/03_البدء/01_ميثاق_المشروع/)).
2. اقرأ ملف `03_01_ميثاق_المشروع_دليل.md` للتعرف على أفضل الممارسات والمدخلات المطلوبة.
3. انسخ قالب `03_01_ميثاق_المشروع_قالب.md` إلى محرر المستندات المفضل لديك (Notion أو Confluence أو Word) أو صدّره مباشرة إلى PDF.

### 2. التوليد التلقائي بالذكاء الاصطناعي (ChatGPT, Claude, Gemini)
توليد وثائق PMO رسمية ومتكاملة في ثوانٍ معدودة:
1. افتح ملف [`forms/ar/parameters.md`](forms/ar/parameters.md) واكتب بيانات مشروعك الأساسية (الاسم، الراعي، الميزانية، والحدود).
2. افتح ملف الموجه `*.md` للمخرج المطلوب (مثال: `04_08_02_سجل_المخاطر.md`).
3. الصق محتوى الملفين مع ملاحظاتك الأولية في المحادثة مع نموذج الذكاء الاصطناعي:
   ```text
   أنت مدير مكتب إدارة مشاريع (PMO Lead) خبير. املأ هذا النموذج بالاستناد إلى المتغيرات العامة للمشروع 
   والملاحظات التالية: [ضع ملاحظات الاجتماع هنا].
   التزم بدقة بإرشادات الحقول، واجعل المخرج بتنسيق Markdown متطابقاً مع هيكل القالب.
   ```
4. ستحصل فوراً على وثيقة مشروع رسمية متكاملة وقابلة للتطبيق والاعتماد!

### 3. الأتمتة البرمجية وتحليل البيانات
- يمكن قراءة ملفات `*.json` و `*.csv` و [`LEXICON.json`](LEXICON.json) برمجياً عبر Python (`pandas`) لإنشاء لوحات تحكم ومتابعة نسب إنجاز مخرجات المشاريع على مستوى المنظمة.
