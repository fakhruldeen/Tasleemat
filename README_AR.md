## 🌟 لمحة عامة
**تسليمات (Tasleemat)** هي حزمة أدوات احترافية لمكتب إدارة المشاريع (PMO). توفر دورة حياة زمنية كاملة لأكثر من 68 مخرجاً ووثيقة احترافية، بدءاً من خرائط طريق المحافظ، ومواثيق المشاريع، وصولاً إلى تخطيط أجايل (Agile)، وحوكمة الذكاء الاصطناعي.

تمت هندسة هذا المستودع خصيصاً للعصر الحديث:
- **🤖 جاهز للذكاء الاصطناعي (LLM):** يتضمن كل نموذج ملف `.json` وموجه (Prompt) بصيغة Markdown مصمم ليتم حقنه مباشرة في نماذج مثل ChatGPT أو Claude لتوليد الوثائق بدقة واحترافية.
- **🌐 ثنائي اللغة (i18n):** مترجم وموطن بالكامل إلى اللغة العربية الرسمية (RTL) بالتوازي مع النماذج الإنجليزية، بما في ذلك أسماء الملفات المترجمة والروابط المرجعية المتقاطعة.
- **🖨️ جاهز للطباعة:** قوالب جذابة مصممة لتُصدّر بشكل مثالي إلى PDF، ومزودة بتوقيعات الاعتماد وأرقام التحكم بالوثائق.
- **📖 جاهز للنشر على GitHub Pages:** مهيأ بالكامل ببيانات Jekyll الوصفية وملفات التنقل.

## 📂 هيكل المستودع
```text
Tasleemat/
├── forms/                 # 🇬🇧 المخرجات باللغة الإنجليزية (الرئيسية)
│   ├── ...
│   └── ar/                # 🇸🇦 المخرجات المعربة (RTL)
│       ├── 00_إدارة_البرامج_والمحافظ/
│       ├── 01_الأعمال_وتسليم_القيمة/
│       ├── ... (المراحل من 02 إلى 07)
├── mapping.md             # السجل الرئيسي لجميع أرقام الوثائق (Document IDs)
└── USAGE_GUIDE_AR.md      # تعليمات تفصيلية حول كيفية استخدام الحزمة
```

## 🛠️ كيفية الاستخدام (البدء السريع)

### 1. الاستخدام اليدوي
انتقل إلى أي مجلد مرحلة (مثال: `03_البدء/01_ميثاق_المشروع`) وافتح ملف `_قالب.md`. يمكنك طباعة هذا الملف، أو تصديره كـ PDF، أو نسخه إلى Word لملئه يدوياً مع فريقك.

### 2. التوليد المدعوم بالذكاء الاصطناعي (موصى به)
هل تريد توليد سجل مخاطر في ثوانٍ؟
1. افتح ملف `parameters.md` وحدد المتغيرات العامة لمشروعك (الاسم، الميزانية، الراعي، إلخ).
2. افتح ملف الـ Prompt أو الـ `.json` الخاص بالوثيقة التي تحتاجها.
3. الصق الموجه، والمتغيرات، وملاحظاتك الأولية في نموذج ذكاء اصطناعي (مثل ChatGPT).
4. شاهد الذكاء الاصطناعي وهو يملأ هيكل الـ `_قالب.md` بالنيابة عنك!
*راجع [USAGE_GUIDE_AR.md](./USAGE_GUIDE_AR.md) للحصول على سير عمل تفصيلي للذكاء الاصطناعي.*
