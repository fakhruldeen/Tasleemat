## 💡 لماذا صُممت تسليمات؟

تعاني معظم مكاتب إدارة المشاريع (PMO) والفرق التنفيذية من إهدار مئات الساعات في إعادة اختراع العجلة باستخدام ملفات Word وExcel مبعثرة وغير متناسقة، أو الاعتماد على ترجمات آلية ضعيفة تفقد المصطلحات الاحترافية دقتها.

**مكتبة تسليمات تقدم الحل المؤسسي الجاهز:**

| التحدي اليومي لمديري المشاريع 😫 | كيف تحل تسليمات هذا التحدي؟ 🚀 |
| :--- | :--- |
| **قوالب مشتتة** في مجلدات متفرقة بصيغ غير موحدة | **114 مخرجاً قياسياً شاملاً** بصيغ ماركداون نظيفة، ومخططات بيانات JSON، وجداول CSV |
| **غياب التعريب المهني الدقيق** أو استخدام ترجمة حرفية ركيكة | **صياغة عربية أصيلة 100% متطابقة 1:1 مع الإنجليزية** وفق مصطلحات PMI وهيئة الحكومة الرقمية |
| **البيروقراطية الزائدة** التي تخنق المشاريع الصغيرة والناشئة | **4 مستويات تخصيص (Tailoring Tiers)** تبدأ من 5 قوالب أساسية وحتى 45+ مخرجاً للمشاريع العملاقة |
| **غياب معايير تدقيق واضحة للمراحل** مما يسبب انحراف النطاق والميزانية | **6 بوابات عبور حوكمية (Stage-Gates)** بقوائم تحقق واضحة ومسؤوليات RACI محددة |
| **عدم جاهزية الوثائق لتقنيات الذكاء الاصطناعي** | دعم كامل لإطار **NIST AI RMF**، وبطاقات نماذج الذكاء الاصطناعي، وموجهات Prompts جاهزة |

## 🚪 بوابات العبور الحوكمية الست (Stage-Gates)

تضمن البوابات المرحلية اتخاذ قرارات مدروسة وخاضعة للتدقيق قبل صرف الميزانيات للمراحل اللاحقة:

```mermaid
flowchart TD
    G0["بوابة 00: فكرة المشروع والمواءمة الاستراتيجية"] --> G1["بوابة 01: اعتماد الميثاق والترخيص الرسمي"]
    G1 --> G2["بوابة 02: اعتماد خطوط الأساس المتكاملة"]
    G2 --> G3["بوابة 03: مراجعة الإنجاز والقبول النوعي"]
    G3 --> G4["بوابة 04: التسليم التشغيلي والجاهزية"]
    G4 --> G5["بوابة 05: الإغلاق النهائي والتحقق من المنافع"]
```

تنتج كل بوابة أحد **3 قرارات حوكمية معتمدة**:
1. 🟢 **موافقة كاملة والعبور (Proceed / Go)**: استيفاء 100% من معايير الخروج، والإذن بصرف الشريحة التالية.
2. 🟡 **موافقة مشروطة (Conditional Pass)**: السماح بالعبور مع خطة عمل تصحيحية (CAPA) بمهلة لا تتجاوز 14 يوماً.
3. 🔴 **إيقاف أو إنهاء (Hold / Terminate)**: وجود انحرافات جوهرية تستدعي إيقاف المشروع أو إعادة هيكلته.

👉 *استكشف المعايير التفاعلية وقوائم التدقيق في **[بوابة حوكمة بوابات العبور](https://fakhr.me/Tasleemat/governance_ar.html)**.*

## 🎯 4 مستويات لتخصيص حجم المشروع (Tailoring Tiers)

تجنب الهدر المكتبي والبيروقراطية باختيار حجم الحزمة المناسب لطبيعة مشروعك ومخاطره:

| مستوى التخصيص | وصف الحزمة وطبيعة المشروع | النطاق والميزانية | عدد المستندات | أبرز المخرجات المتضمنة |
| :--- | :--- | :--- | :---: | :--- |
| **المستوى 1: مصغر (Micro)** | مشاريع سريعة ومحدودة المخاطر | < 200 ألف ريال • < 3 أشهر | **5 مخرجات** | ميثاق مصغر، جدول إنجاز، سجل إجراءات، تقرير حالة، محضر تسليم |
| **المستوى 2: أساسي (Core)** | مشاريع إدارية متوسطة التعقيد | 200 ألف - 2 مليون ريال • 3-9 أشهر | **18 مخرجاً** | خطوط الأساس (نطاق، جدول، ميزانية)، مصفوفة مخاطر، مصفوفة RACI، إدارة التغيير |
| **المستوى 3: مؤسسي (Enterprise)** | تحولات استراتيجية ومشاريع متعددة الأطراف | > 2 مليون ريال • > 9 أشهر | **45+ مخرجاً** | كافة بوابات العبور الـ 6، ملفات التدقيق، حزم المشتريات، متطلبات ESG والأمن السيبراني |
| **المستوى 4: مرن / ذكاء اصطناعي** | تطوير البرمجيات ونماذج الذكاء الاصطناعي | دورات سبرنت دورية / ML Lifecycle | **25 مخرجاً** | رؤية المنتج، سجلات سبرنت، مؤشرات التدفق، بطاقات نماذج AI، واجتماعات الدروس |

## ⚡ طرق استخدام تسليمات

### 1. الاستعراض السريع عبر الويب *(الأسرع والأسهل)*
تصفح البوابة الرقمية التفاعلية للبحث، الفلترة، ونسخ القوالب بضغطة زر واحدة:
- 🌐 **[https://fakhr.me/Tasleemat/README_AR.html](https://fakhr.me/Tasleemat/README_AR.html)**
- 📋 **[مستكشف الـ 114 تسليمة](https://fakhr.me/Tasleemat/catalog/ar/index.html)**

### 2. الاستخدام البرمجي عبر مكتبة بايثون (`import tasleemat`)
تثبيت الحزمة الرسمية مباشرة من مستودع PyPI للوصول البرمجي إلى القوالب، مخططات البيانات، والتحقق:
```bash
pip install tasleemat
```
```python
import tasleemat

# 1. استكشاف التسليمات المسجلة (114 تسليمة)
charter = tasleemat.get_artifact_definition("PMO-03.01")

# 2. استرجاع القوالب والأدلة مباشرة
ar_template = tasleemat.get_artifact_asset("PMO-03.01", role="template", lang="ar")

# 3. التحقق الهيكلي من البيانات وفق مخططات JSON
report = tasleemat.validate_artifact_data("PMO-03.01", {"project_name": "مشروع التحول"}, mode="draft")
print(f"صلاحية المسودة: {report.valid}, التنبيهات: {len(report.warnings)}")

# 4. تصدير المستند كصفحة HTML مهيأة للطباعة دون إنترنت
tasleemat.render_artifact("PMO-03.01", lang="ar", out_path="./charter_ar.html")
```

### 3. الأتمتة عبر أداة السطر البرمجي CLI
توليد بيئة حوكمة المشروع تلقائياً عبر موجه الأوامر:
```bash

tasleemat init --tier 2 --pack agile --lang ar --out ./مشروعي
```

### 4. النسخ والاستخدام المباشر داخل GitHub
كافة القوالب مكتوبة بلغة ماركداون نظيفة وجاهزة للاستخدام في Notion أو Obsidian أو Confluence:

## 🤖 استخدام تسليمات ومواصفة OKF مع نماذج الذكاء الاصطناعي (Claude, ChatGPT, OpenCode)

صُممت مكتبة تسليمات لتكون جاهزة للعمل الفوري مع **النماذج اللغوية الكبيرة (LLMs)** وأدوات البرمجة الذكية (Claude, ChatGPT, OpenCode, Cursor, GitHub Copilot):

### 1. في المحادثات المباشرة (ChatGPT و Claude)

تحتوي كل تسليمة داخل مجلد `forms/ar/` على ملف موجه ذكي مهندس مسبقاً (`*.md`) وقالب وثائقي مكتمل (`*_قالب.md`):

#### أ. التوجيه المباشر في المحادثة:
1. **انسخ الموجه (Prompt)**: افتح ملف الموجه للتسليمة المطلوبة (مثلاً: `03_01_Project_Charter.md` باللغة العربية).
2. **ألصقه في ChatGPT أو Claude**: الصق الموجه كتعليمات للنظام أو في بداية رسالتك.
3. **أرفق ملاحظات الاجتماع أو المشروع**:
   ```text
   [الصق موجه تسليمات هنا]

   ملاحظات انطلاق المشروع:
   - اسم المشروع: منصة التحول اللوجستي الذكي
   - الراعي: الهيئة العامة للنقل
   - الميزانية: 12 مليون ريال
   - المدة: 14 شهراً
   - النطاق: أتمتة مراكز الفرز وتتبع الأسطول بإنترنت الأشياء
   ```
4. **النتيجة**: يقوم النموذج بتوليد وثيقة ميثاق مشروع احترافية ومعتمدة، متوافقة مع جداول ضبط المستندات والاعتمادات الرسمية.

#### ب. نماذج Custom GPTs ومشاريع Claude Projects:
- أنشئ مشروعاً بعنوان *"مدير مكتب إدارة المشاريع PMO"*.
- ارفع مجلد `forms/` وقاموس المصطلحات `docs/LEXICON.json` كملفات معرفية للمشروع.
- عيّن التعليمات: *"استخدم دائماً هيكلية مخرجات تسليمات وجداول ضبط المستند والمصطلحات الموحدة لجميع الوثائق المطلوبة."*

### 3. داخل أطر عمل الوكلاء متعددي المهام (CrewAI و LangChain و LlamaIndex)

بفضل توفر مكتبة `tasleemat` الرسمية على PyPI (`pip install tasleemat`)، يمكن لوكلاء الذكاء الاصطناعي استدعاء وظائف الحوكمة مباشرة:

#### أداة مخصصة لـ CrewAI:
```python
from crewai.tools import tool
import tasleemat

@tool("PMO Deliverable Retriever")
def get_pmo_deliverable(artifact_id: str, role: str = "template", lang: str = "ar") -> str:
    """استرجاع قوالب وأدلة وثائق إدارة المشاريع الرسمية (مثل PMO-03.01)."""
    return tasleemat.get_artifact_asset(artifact_id, role, lang)
```

#### أداة مخصصة لـ LangChain:
```python
from langchain.tools import BaseTool
from pydantic import BaseModel, Field
import tasleemat

class PMOFetchInput(BaseModel):
    artifact_id: str = Field(description="معرّف المخرج الحوكمي مثل 'PMO-03.01'")
    role: str = Field(default="template", description="نوع الأصل: 'template' أو 'guide' أو 'prompt' أو 'schema'")
    lang: str = Field(default="ar", description="اللغة: 'ar' أو 'en'")

class PMOFetchTool(BaseTool):
    name: str = "pmo_fetch_asset"
    description: str = "استرجاع قوالب وأدلة إدارة المشاريع المتوافقة مع معايير PMI وهيئة الحكومة الرقمية."
    args_schema: type[BaseModel] = PMOFetchInput

    def _run(self, artifact_id: str, role: str = "template", lang: str = "ar") -> str:
        return tasleemat.get_artifact_asset(artifact_id, role=role, lang=lang)
```

### 4. استخدام حزمة بيانات Open Knowledge Foundation (OKF) برمجياً مع النماذج

تتوافق تسليمات مع معيار **OKF Frictionless Data Package** عبر ملف [`datapackage.json`](datapackage.json) الجذري الذي يفهرس 228 مخطط بيانات JSON:

#### أ. استدعاء الدوال الذكية (Function Calling & Tool Use)
زوّد نماذج OpenAI أو Claude بمخططات JSON المعتمدة لتوليد حقول دقيقة ومقيدة دون اختلاق حقول وهمية:
```python
import tasleemat

# استخراج مخطط البيانات المعتمد للتسليمة
schema = tasleemat.get_artifact_asset("PMO-03.01", role="schema", lang="ar")

# تمريره كمعاملات للأداة الذكية في Claude أو OpenAI
tool_definition = {
    "name": "create_project_charter",
    "description": "توليد ميثاق مشروع معتمد وفق PMI",
    "parameters": schema
}
```

#### ب. حلقات التحقق والتصحيح الذاتي التلقائي (Self-Correction Loops)
استخدم `validate_artifact_data` للتحقق البرمجي التلقائي وإعادة توجيه النموذج لإصلاح الأخطاء ذاتياً:
```python
import tasleemat

# التحقق من مخرجات النموذج
report = tasleemat.validate_artifact_data("PMO-03.01", llm_output, mode="strict")

# إذا وُجدت أخطاء، زوّد النموذج بمسارات الأخطاء لتصحيحها فوراً
if not report.valid:
    correction_prompt = f"البيانات تحتوي أخطاء هيكلية: {[(e.field_path, e.message) for e in report.errors]}، يرجى التصحيح."
```

- **مؤسسة المعرفة المفتوحة (OKF)**: مخططات البيانات المتزامنة بصيغ Frictionless Data JSON وCSV.
- **معايير الاستدامة والحوكمة البيئية والاجتماعية ESG / UN SDGs**: دمج أهداف التنمية المستدامة في ميثاق المشروع ودراسات الجدوى.
