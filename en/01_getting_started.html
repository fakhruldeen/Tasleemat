🚀 Getting Started with Tasleemat PMO Operating System

Document ID: TASLEEMAT-GUIDE-01-GETTING-STARTED
Version: 2.0
Target Audience: Project Managers, PMO Directors, Agile Coaches, Project Sponsors, AI Leads

🎯 Welcome to Tasleemat

Tasleemat (تسليمات) is a high-performance, enterprise-grade Project Management Office (PMO) Operating System. It delivers 102 standardized, bilingual (English & Arabic) deliverable forms engineered in clean Markdown, accompanied by structural schemas (*.json, *.csv) and real-world reference implementations.

Whether you are running a multi-million-dollar infrastructure transformation, a lean agile sprint, or an innovative GenAI deployment, Tasleemat provides the exact governance baseline you need without bureaucratic bloat.

🧭 Step-by-Step Onboarding Workflow

Phase 1: Day 1 to Day 7 — Project Discovery & Sizing

  1. Determine Project Tier & Category:
  2. Consult 05_tailoring_profiles.md.
  3. Classify your initiative into Tier 1 (Enterprise / Strategic), Tier 2 (Medium / Core), Tier 3 (Small / Fast-Track Agile), or Tier 4 (AI / Emerging Tech).
  4. Review Stage-Gate Requirements:
  5. Read 04_stage_gates_and_governance.md to understand the 6 governance milestones (Gate 0 to Gate 5).
  6. Draft the Strategic Foundation:
  7. If starting at portfolio level: Complete 00_01 Portfolio Roadmap and 00_06 OKR Alignment.
  8. Complete 01_01 Business Case and 03_01 Project Charter.

Phase 2: Day 8 to Day 21 — Planning & Baseline Authorization

  1. Establish the Triple Constraint Baseline:
  2. Scope: Complete 04_02_05 Scope Statement and 04_02_06 WBS.
  3. Schedule: Complete 04_03_08 Project Schedule.
  4. Cost: Complete 04_04_04 Cost Baseline.
  5. Assign Governance Roles & RACI:
  6. Consult 06_raci_authority_matrix.md and fill 04_06_04 RACI Matrix.
  7. Pass Gate 2 (Integrated Baseline Review):
  8. Present the integrated baseline to the PMO and Sponsor for formal sign-off.

Phase 3: Day 22 Onward — Execution, Control, & Stage Gates

  1. Maintain Live Operational Logs:
  2. Track issues in 05_01 Issue Log.
  3. Log decisions in 05_02 Decision Log.
  4. Process change requests through 05_03 Change Request and 05_04 Change Log.
  5. Measure Value & Variances:
  6. Run weekly or bi-weekly 06_01 Project Status Report.
  7. Calculate EVM metrics via 06_05 Earned Value Analysis.
  8. Pass Gate 4 & Gate 5 (Acceptance & Closure):
  9. Secure customer signoff using 06_08 Product Acceptance Form.
  10. Handover to ops via 07_04 Transition Checklist.
  11. Archive organizational assets using 07_03 Closeout Report and 07_01 Lessons Learned.

🗂️ How to Use Forms, Guides, and Examples

Every form in Tasleemat follows a strict three-part triad:

forms/en/03_Initiating/01_Project_Charter/
├── 03_01_Project_Charter_Template.md   # The pure fillable template
├── 03_01_Project_Charter_Guide.md      # Detailed instructions & alignment
├── 03_01_Project_Charter.json          # Machine-readable schema definition
└── 03_01_Project_Charter.csv           # Structured table column headers

examples/en/03_Initiating/01_Project_Charter/
└── 03_01_Project_Charter_Example.md    # Fully filled enterprise example
  1. For the Author (PM / Lead):
  2. Open *_Guide.md first to understand mandatory inputs, RACI, and dependencies.
  3. Copy *_Template.md to your working folder or project repo.
  4. Fill in each bracketed placeholder [ Specify ... ].
  5. Refer to *_Example.md in examples/ for benchmark inspiration.
  6. For the Approver (Sponsor / PMO Director):
  7. Check the Document Control & Sign-off Table at the bottom of each deliverable.
  8. Verify alignment with upstream dependencies in 07_document_dependencies.md.
